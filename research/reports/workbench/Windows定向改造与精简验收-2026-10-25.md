## 范围与结果

用户已授权按[执行方案](../../../docs/plans/Windows学习工作区定向改造执行方案-2026-10-25.md)实施，并在本轮明确选择先交付 Windows 改造，B站完整集成另行安排。此次不包含 Android、八平台全面集成、交互书新内部设计或旧13场景全量验收。

- 增加默认未分类目录，沿用现有复制／同名保留机制；不先建课程也能进入原生对话。
- 将浏览课程、当前对话和对话可读工作区分开；使用原生会话列表及菜单组件，一段对话可以添加多个工作区，浏览课程不改变它们。
- 保留旧对话课程作为默认保存位置和历史兼容身份；独立对话默认保存未分类，用户明确指定的课程覆盖本次保存目标。
- 移除桌面成果／任务标签和专门来源面板；保留能力在原对话显示进度、文件入口和引用。交互书复用既有目录确认与分章阅读，不新增内部设计。
- 取消自动课程扫描、索引和 OCR 新执行；关闭打开视频／播放时的字幕处理。旧识别、字幕、成果及快照仍保存，已取消的修改入口返回明确拒绝，不删除历史数据。
- PDF 使用原生文字层，选区附近显示“添加到对话”；“这页／这份资料”的明确提问按需读取允许内容，普通聊天不自动附带正文。
- 字幕登记为原生 Skill；普通问题不授予字幕工具，明确请求可读已有字幕或创建指定视频的本地转写任务。没有改动本地 ASR 引擎及模型版本。
- 生成文档写入课程目录，重复发布复用同一文件；检测到用户手改时拒绝覆盖。生成来源身份保留，文档中的文件来源链接可回到资料区。默认不自动打开，明确要求生成并打开时才使用该请求的打开意图。

主要实现入口：[工作区关系](../../../backend/src/learning_app/workspaces.py)、[桌面桥接](../../../desktop/client/learning-bridge.js)、[原文按需读取](../../../backend/src/learning_app/workbench/on_demand_sources.py)、[生成文档保存](../../../backend/src/learning_app/workbench/artifact_files.py)。公开 DTO 以[生成契约](../../../contracts/openapi.json)为准。

## 保留的失败及修复记录

- 新表最初加入旧迁移所用 metadata，造成新库重复建表；已隔离 metadata，并同步实际 schema head。未对用户数据库手动试错。
- 工作区保存最初嵌套开启 SQLite 写事务，出现锁冲突；已改为同一事务查询，相关用例复测通过。
- 浏览器验证器最初未区分两个刷新按钮及文件列表的 option 角色；只修正选择器，前面通过的工作区结果复用。
- PDF 固定清单的锁定摘要对应 CRLF，而 Git 工作树为等价 LF；已限定接受能还原到固定摘要的换行投影，依赖版本及各资源文件摘要未放宽。原生文字层验证通过。
- 独立对话引用其他课程的可见 PDF 仍被旧前端课程限制拦截；已改为核对实际可见资料身份，跨课选区流程通过。
- 浮动选区操作最初与旧 right／bottom 定位共同撑大覆盖区域；已限定为选区附近的小型入口，实际截图复核通过。
- 文件发布最初以“文件必须存在”的方式检查新目标，数据库成果有记录但未写入文件；已修复，并补上实际文件发布断言，定向保存及宿主回放通过。
- 程序派生的当前页快照／工作区范围与用户草稿不同，旧对账会残留已发送输入；已保存服务端可信的用户输入摘要进行清稿对账，后续用户编辑仍受保护。
- 取消旧写接口后，其历史 DTO 从生成契约消失，影响保留组件编译；改为保留 deprecated 契约、执行时统一拒绝，不恢复业务能力。
- 字幕测试夹具的参数名和聊天初始化问题已修正，只复测对应三条准入用例，未扩成完整字幕矩阵。

本次仅按用户确认的六项界面范围调整。课程和未分类是同一目录树的根节点，左侧只展开子文件夹，中央浏览文件；恢复原生账号菜单、全部设置内容页和“＋”菜单；附加数据与存储页。原生账号与余额仍按真实登录状态呈现，未伪造登录／余额。原文引用成功后清除原选区并保持阅读位置，失败保留；按钮使用Harness主题。学习状态与文档引用移入turnTail内容扩展，原生复制／评价／分支／用量按钮行不再承载项目额外控件。
