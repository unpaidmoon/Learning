# UI 颜色与命名算符局部引用修复

日期：2026-10-22。依据用户提供的按钮、排序／历史菜单、弹窗及 `det` 局部引用截图，修改正式前端；使用等价合成资料复现，没有读取真实聊天、课程文件或屏幕其他范围。

## 原因与修改

**按钮文字同色：** `styles.css` 的全局 `button,input,select,textarea { color: inherit }` 未放在 CSS layer 内，优先级高于 Tailwind utilities 中的 `text-primary-foreground` 等组件颜色。真实浏览器观察到浅色主按钮文字／底色均为 `rgb(26,28,31)`，深色均为白色，对比度为 1。`font:inherit` 同样会盖住组件字号／字重。现在只把这两个基础继承规则移入 `@layer base`，保留按钮组件和唯一主题 token，由变体颜色正常生效；不逐个按钮加 `!important`。

**原生菜单底色缺失：** `select` 已继承文字色，但 `option`／`optgroup` 没有自己的底色。现在为选项同时指定主题前景和抬升背景，浅色壳显式 `color-scheme:light`、深色壳沿用 dark。真实展开的排序和历史菜单已分别截图检查，包括当前项与未选项。

**局部 `det` 不可映射：** 固定 `katex@0.16.22` 的命名算符 AST 节点（如 `\det`、`\sin`、`\log`）没有 `loc`。原映射只处理带位置的字母、符号等叶节点，因此完整公式可引用，经过算符的局部范围仍失败。现在把解析器确认的命名算符与原始 KaTeX lexer token 对账，确认数量一致后补位置；不从显示文字猜第几次出现。克隆 lexer 状态，不修改原解析树；token 尾部消耗的空白不带进未选范围。既有受 nonce 限制的 `htmlData` 信任、原始 UTF-16 范围及后台来源校验保留。

范围 `\det M = \det A \det` 可单独引用，不包含后面的 `B`、乘积结果或后文；`M = \det A` 同样可引用。单词 `det` 内只选 `de` 仍明确拒绝，不把 `t` 补入。模糊宏展开、破碎结构、不连续源码及原先拒绝的跨分子／分母范围不放宽。实现还校验插入映射后的整个公式宽度与原 KaTeX 基线一致，本例实际宽差为 0。
