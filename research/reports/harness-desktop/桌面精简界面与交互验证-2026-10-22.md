# 桌面精简界面与交互验证

日期：2026-10-22（Asia/Shanghai）。工作包状态只在 [MVP 计划](../../../docs/plans/MVP开发计划.md) 维护。用户本轮授权直接实施界面评审，随后以圈图明确“精简、只展示有用信息、注意力集中在需要的地方”，要求统一文字，并显式调用 reverse-engineer-anything 优化交互／动效。

## 实现范围

- 保留左课程目录／中资料／右 AI；默认课程 240px、AI 440px，中间自适应。窄窗口使用原生侧栏收起语义，拖宽继续可用。
- 原生输入框、消息、图片／文档附件和模型选择仍为原组件实例。空聊删除欢迎品牌、重复课程选择和说明，输入区停靠底部；当前标题使用“新对话”或实际对话标题，不展示内部 ID。
- “文件”改为简洁页签；课程只保留一次名称，目录重复标题移除，重命名／刷新／移除等操作收进同一课程行。对话和课程工具在悬停／键盘聚焦时显露。
- 设置合并一个原生菜单入口，提供账号与模型及浅色／深色／跟随系统，主题使用原生选择勾选。取消常驻项目计数，剪切等实际待处理状态仍可见；文件操作按选中状态出现。
- 课程名、文件名、页签、对话标题的实际 computed font-family 完全一致，沿 Harness `--dsw-font-family`，主字号均为 14px；次要控件保持较低层级，代码和 KaTeX 不被统一字体规则覆盖。
- 文件卡片两行名称和完整名称提示；可见视频封面只读既有缓存，未准备好保留类型图标。封面读取不登记／打开业务视频、不前台 hash 原件、不改最近使用，不进入问答附件。
- 短反馈与菜单用原生 fast token（100ms），项目面板使用默认 token（200ms）；拖动时取消尺寸动画，reduced-motion 下关闭相应动效。文件弹窗正确进入焦点，Tab 不轻易离开弹窗，Esc 关闭后返回原控件；操作进行中沿用禁用规则。

课程及文件操作仍经既有操作身份、持久检查点与未知先对账路径，没有建立第二套文件管理或聊天数据。

## REA 依据与范围

实际制品可见 fast／默认／slow 为 100／200／300ms、easing 为 `cubic-bezier(.4,0,.2,1)`。侧栏实际还使用 150ms，frame／rightbar 有 300ms；本项目选取 token 做轻量适配，不声称原生全部组件时长相同。所查菜单 module 没有建立通用弹出时长，新增 100ms 菜单动效属于项目设计选择。字体 token 接入原生用户偏好及 Segoe UI／微软雅黑等回退栈。

- 首次旧流程验证已到完成截图，但 Windows fixture 关机在 WebSocket 回收阶段超时，未取得完整最终记录，不作为最终通过。只为合成服务配置了 5 秒 graceful shutdown，最终批次完成正常清理；这不是普通停止回答时杀 Host 的实现。
- 本轮真实模型调用为 0；上述流式与停止是本地 provider fixture，实际 Electron 与静态 REA 也不冒充真实模型。此前真实模型及思考截断记录仍保留原批次，不转记为本轮。
