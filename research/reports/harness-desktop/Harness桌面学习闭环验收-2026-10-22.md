# Harness 桌面学习闭环验收

日期：2026-10-22（Asia/Shanghai）。范围：用户授权的独立桌面视频截图问答试用。工作包状态仅在 [MVP 计划](../../../docs/plans/MVP开发计划.md) 维护。

## 最终行为与来源

用户最终要求是以 Harness 的视觉和交互为基础，整体布局与功能设计继续沿用本项目：左侧课程目录、中间资料区、右侧 AI。此次加载固定 SEA 的原版客户端，复用原生 React、输入框、消息渲染、模型菜单与历史菜单；项目模块提供课程目录、原生选文件夹创建课程、中间固定“文件”页及可关闭视频标签。没有将官方聊天主区／右资料结构当作用户最终决定。

已接通视频播放、位置保存、用户截图并确认范围、原生输入框发送、流式回答、生成中停止、同一对话追问及历史恢复。关闭最后视频回到文件页，AI 收放和资料切换保持聊天；显式新对话创建业务空聊且不派发模型。

`desktop/main.cjs` 是基于上游窗口代码缩减的独立 Electron carrier，原生客户端资源来自固定 SEA；不称为完整官方桌面构建。SEA 版本 `0.2.1-rc.2`、内嵌 UI build `332895e`，参考源码 `687f282e8625c6b8d11ff58211a90524be2e4317`。两者分列于 [desktop.lock.json](../../../harness/desktop.lock.json)，不冒充同一提交构建。缺失的浏览器 Workspace provider 由三份未修改的固定官方源码编译补足，来源与 hash 见 [构建清单](../../../desktop/native-workspace.sources.json)。Electron 固定 `44.7.0`。

发送、停止、模型选择和原生新建会话均经过项目业务后台，聊天及生成身份映射持久化。Host token／签名 cookie 不进入 renderer；写操作与 mux 核应用会话、Origin 和 CSRF，其他写操作默认拒绝。固定执行 guard 继续阻断任意工具、自动联网、额外视频／屏幕获取。默认桌面业务数据独立于原浏览器实例，未迁移或删除用户资产。

真实层三问依次为确认图中的二次方程、长推导中主动停止、同会话继续求根并验根。第一问完成 415 字，根 2、3 及验算正确；第二问在正文已经输出、provider 返回 200 且仍活动时点击原生停止，最终 `cancelled`，保留已收正文 666 字，provider 观测取消，Host 存活；第三问完成 122 字且同一 native session。数学结论仅限此生成样例，不外推学习价值或任意数学准确率。

## 开发失败与保留证据

r1 的原生 CSP 动态加载限制、r2 的缺 Workspace／terminal provider、r3 的 mux 断流及输入不可编辑、r4 的双空聊初始化、r5／r6 的内部路由标记标题、r7 的原生单槽相同优先级冲突均保留在各自输出目录。修复后由 r8 冻结验证覆盖，未把先前失败覆盖或重标成功。公开参考源码与实际制品有差异，所有接缝以实际运行结果为准。

单独修复并测试了模型／思考选择重启丢失、原生创建回放重复、视频卸载末次位置保存以及窗口启动失败的安全回滚。正常停止只取消单生成；窗口关闭隐藏不等于后台退出。测试和窗口所属进程已经清理，`18980`、`18982`、`18990`、默认检查 `8766` 及调试端口已关闭；原用户 `8765` 实例未由本轮停止。

## 使用与未覆盖

双击根目录“启动Harness桌面.cmd”。默认业务数据为 `.runtime/desktop/app/data`，运行态为 `.runtime/desktop/app/run`，后台端口 `8766`；可在课程入口创建课程、选择真实文件夹，再打开视频。准备工具为 `scripts/desktop/bootstrap.py --build-native`；原生 provider 可用 `scripts/desktop/build-native.mjs --check` 核对。

- 本次真实模型证据来自显式 API Key 路线。桌面官方账号登录／授权未真实复测，原浏览器账号旧证据不转记为本次通过，也不自动回退到 API Key。
- 当前执行为保护当前题图，会随后续问题重附已确认历史题图；原生后续用户行可能再次显示该图。范围仍是已确认历史，没有补取原帧或相邻帧。
- 此入口未整体迁移其他资料阅读、完整文件整理、PDF／文本附件、公式局部引用、完整全屏工作区、字幕、知识库、Android／同步或安装发行。原有浏览器功能继续保留。
- 目录选择复用已有 Windows 原生实现；本轮默认启动检查只打开创建表单，没有代用户完成真实文件夹选择。课程目录还需用户实际素材体验。
- 合成浏览器、真实模型、实际 Electron 窗口和用户主观体验分别报告。尚未取得用户正常学习、主观视觉及普遍速度目标验收，不称完整首版。
