- 正式界面采用 Codex 风格浅深主题，取消大肥鱼；左侧顶部切换课程、下方当前课程文件树，中间多标签单资料，右侧 AI 及其顶部历史入口。

- 视频控件、标签暂停／恢复、工作区全屏与右侧 AI、应用内拖选截图、精确文字／公式范围引用卡片、保存重开及错误恢复已接入既有业务存储与生成系统。
- 先提供固定 Harness 官方 PKCE 入口，并由用户在官方页面完成登录。默认账号、显式 API Key；模型目录及额度优先使用官方，失败不切换凭据。Host 就绪与问答可用独立表达。
- 新增完整 [前端开发规范](../../../docs/architecture/前端开发规范.md)，供后续页面／组件开发执行；接口见 [应用契约](../../../docs/architecture/应用契约.md)。

REA 建立本机 Codex 制品、入口和覆盖范围，CSS 另经独立无执行提取。包版本 `26.1013.4894.0`，包内应用 `26.1013.40934`，ASAR SHA-256 为 `bbec1d64e135b718a154b31655bb8ad9a39472bac1b2cabba991a9d97a339dd8`。选源只有 `package.json` 和 `webview/index.html`，不能声称完整前端反编译或运行态主题已观测；八项原生伴随资源完整性差异保留，没有执行它们。证据见 [静态记录](Codex前端静态证据-2026-10-21.json)。

这些 input 是归一化字段原值，cache usage 另在 raw observation 保存，不在此混成完整输入或计费总量。六次中四次已结算、两次取消无最终用量；两次起始 output=0 不当最终零，独立 reasoning_tokens 缺失仍未知。累计流式快照不相加，未把四次已知用量称为六次完整总量。

两次停止均记录了点击时 provider 尚活动、已有正文、取消被观察、部分回答保留、Host 存活及后续同会话完成；不是 idle cancel。每组只有一个会话，三次实际出站，没有隐藏重发。两组都确认只包含允许选区、原图未传。

本次小样本题是 `x²−5x+6=0`，四次完整回答读取条件、分解为 `(x−2)(x−3)`、求根公式判别式 1、得到 2／3 并代入检验的主要步骤核查一致。它不是代表数学题型准确率、复杂证明、手写识别或新一轮 V3 数学矩阵验收；历史 Pro／none 的 Taylor 符号错误保持原失败。表内首正文只是传输诊断，不是首次有用内容或普遍 10 秒目标的证明。

## 4. 原失败与修复范围

- 初次 DOM 截图数值断言较弱，曾错误遗漏分式形态；后续目视复核发现分子／分母丢失，修复零高度祖先、边框及可见子节点保留，r2 实际像素及目视完整。原失败见 [视觉复核](snapshot-smoke-20261021-r1-visual-review.json)。
- 完整浏览器 r1 的工具选择器把中文转成字面量转义，修正 runner 后另开 r2；不归为应用缺陷。
- r2 发现 ESC 未可靠退出工作区，增加只针对当前全屏目标的显式退出及截图取消优先，r3／r4 复验。
- r3 发现截图上传成功时输入框仍 disabled，早期 focus 无效；修复为 DOM 解除禁用后执行当前聊天的聚焦请求，r4 复验。
- 单元／代码检查另修复同版本资料重新打开仍残留旧错误及迟到正文、引用空发、截图失败漏图、账号就绪误报、文件部分写入和链接目标边界。各自对应新回归，不把局部成功冒充全套。

失败原目录均保留；新轮次没有覆盖旧记录，也没有把旧冻结 hash 改成新实现。

## 5. 使用与未覆盖

双击根目录 `启动学习.cmd`，在“账号与模型”查看保存的官方登录状态或主动切换 API Key；打开课程文件夹，在左侧文件树中点击资料。`Ctrl+Shift+S` 拖选进草稿、补问后发送；选回答中的文字／公式后点临时“添加到对话”。全屏 `Ctrl+Shift+A`／右侧触边唤起 AI，关闭后纯视频续播。全部操作规则见 [README](../../../README.md) 和 [前端开发规范](../../../docs/architecture/前端开发规范.md)。

未覆盖：用户实际审美与正常学习评价；新原生选择器的人实际点击及实体键盘体验；多显示器／缩放／不同机器字体和完整无障碍专项；无法精确映射的复杂、不连续公式与宏局部范围。Windows 文件 symlink 创建权限不足的实际案例明确跳过，junction 拒绝已有证据。

当前内置资料阅读是视频／图片／文本；PDF／Office 提供系统打开，不宣称内置 PDF／Office 或其截图完整支持。没有开展完整 Office／ASR、知识库用途、Android／同步、自由多窗口、完整安装包。Vite chunk 提示及上游测试弃用警告保留，未据此编造性能或兼容结论。

所有本轮浏览器、Vite、Host、边界、启动器实例均按所属关系清理；没有按 Python／Node／Harness 名称批量结束进程。未删除原始资料、聊天、附件、用户已有视觉材料或历史证据。
