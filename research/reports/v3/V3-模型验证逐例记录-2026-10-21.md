# V3 模型、数学与活动停止逐例记录

日期：2026-10-21（Asia/Shanghai）。本记录只覆盖 MVP-A 对应的正式模型链与定向数学验证；实际浏览器操作和综合交付由本轮综合报告记录。**当前证据支持继续试用，用户数次实际学习、操作对照及愿意继续使用的评价仍待完成，不能宣布 V3 学习价值已验收。**

## 输入、执行与审阅口径

采用正式同源 HTTP → GenerationService → 固定 Harness Host → 官方 provider 路由；没有直接模型旁路、OCR、评分模型、自动重发或自动降级。密钥只由后台既有私有配置读取。模型、思考、输出上限和观察时限在各批冻结记录中显式保存。

合成基线采用[18-ID 清单](../../../tests/fixtures/v3/cases.json)及[生成器说明](../../../tests/fixtures/v3/README.md)：15 个可执行合成案例共 17 回合；H01/H03 没有已确认真实手写，不打印替代。H02 按 V1 批准 manifest 精确复用已提交的 1280×540 JPEG，hash 为 `37e7e83aadf641d46d0113a2c74530159ca17be783bea5fe1567eed46ac6c3fb`。本轮没有读取真实视频画面、屏幕、邻帧或更大的未确认图片。

数学核查对照独立写明的解析预期，逐项检查读题、方法前提、运算及结论；属于助手解析核查。M01/L02 的历史用户确认与其他题的助手预期分开标明，不把模型自评、关键词或另一个模型评分当作标准答案。原回答、失败、provider SSE、数据库和冻结摘要保留，后续修复另开批次。

## 真实活动停止、追问与时间

初始 STOP 在 HTTP 显示 running 且可见 50 字符时请求停止，但 provider 已先完成、业务逐 token 事务摄入积压。该例最终 completed，不能算真实活动停止。修复将连续事件批摄入，保留事件顺序、水位、终态和用量语义；本轮没有用杀整个宿主代替停止。

新 STOP 在发送后 8594ms 看见 44 正文字符，此刻边界同时证明：实际派发已起、没有 `request_finished`、当前原始 SSE 没有 `message_stop`。之后 8750ms 收到 durable cancelled，保留 **82 字符**，provider `cancel_observed=true`、`timed_out=false`，中断用量保持未知。原始 SSE 字节数、hash、UTC 纳秒及断流证据随批保存。

随后同一 chat、binding、Harness session、epoch 和 Host 实例继续追问，分母明确更正为 2x³；实际请求仍只有该会话确认题图，Taylor 余项、洛必达条件和结果 **1/6** 均正确。没有为停止重建宿主。该追问首正文 31.829 秒、实质推导锚点 32.657 秒、完成 35.688 秒，未达到 10 秒目标。

初始正常数学、更正及手写共 17 回合，助手按实际 HTTP 快照中的完整实质推导锚点核定有用内容为 **1.641～5.329 秒**。这是轮询观测上界，不是首字符、thinking、浏览器渲染或用户阅读计时，不能据此宣称用户学习流程普遍达到 10 秒。pro / high 控制中 M01 有用锚点 35.859 秒、完成 38.031 秒；T01 有用锚点 13.656 秒、完成 15.875 秒，同样保留等待差异，不以速度覆盖正确性。

## 冻结、清理与未覆盖

每批保存前后源码摘要。初始基线运行期间只有三个前端文件改变，backend/Harness 保持；pro / high 旧图文批期间后台持久化修复改变，不能声明全量不变或用该批验收最终后台；pro / high 纯文字批只有聊天前端改变。最终活动停止批只有根 `package.json` 检查入口修改，执行用 backend/Harness 没变。各批差异逐项保留，不重写旧冻结 hash。

所有真实批次均停止本批所属应用/Host 进程，记录 `remaining_pids=[]`、所属端口关闭；用户原件及旧记录未清理。最终停止后仍能追问的证据来自清理之前的同一会话，不把重新启动后成功当作停止未杀宿主。

尚未覆盖：用户主动从真实网课提交的新题图、H01/H03 真手写、复杂数学一综合证明、数次正常学习观察、同使用者操作对照、维护负担与愿意日常使用的评价。完整 Office/ASR、知识库、Android、同步、多窗口、公式局部选择与安装包未因此启动或假称可用。
