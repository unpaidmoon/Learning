# 中国大学 MOOC 官方 API 与现成工具接入范围调研

检索日期：2026-10-23。目标是 **中国大学 MOOC／icourse163.org**，不包括 imooc.com 慕课网、icourses.cn 爱课程旧视频平台、网易云课堂或学堂在线。仅研究与继续讨论，不代表需求确认、接口开通或实施授权。

本日后续：用户经逐项grilling已明确“收口”，[正式中国大学MOOC接入需求](../../docs/product/中国大学MOOC接入需求收口-2026-10-23.md)为产品范围主要来源，先文档、不开发。已确认只读、手动选择期次及资源、视频／资料／题目和变化提醒；明确不导入公告、大纲、评分标准、考核时间及讨论答疑。下文建议与“待确认”按研究形成时理解，产品边界以后续收口为准；接口和账号能力仍未实测，不将候选工具功能全部视为已采用。

## 证据范围

本轮读取官方文档、作者仓库 README、固定提交源码、GitHub live 状态与 issue。未安装工具、登录账户、获取私人 Cookie、请求真实课程媒体、提交学习记录或进行模型测试。

下文区分四层：官方机构合作契约、第三方作者声明、固定源码实际分支、本项目真实运行。前三层均不能冒充第四层；项目未归档也不能证明当前平台兼容。未核实的普通个人接口不表述为确定不存在。

## 官方开放平台：有接口，但不是普通个人 token 的证明

| 官方证据 | 已确认的范围 | 不能推导的范围 |
| --- | --- | --- |
| [开放平台介绍](https://docs.icourse163.org/) | 提供资源对接、账号单点跳转等客户方案 | 文档公开不等于普通学生可自行取得全部接口权限 |
| [课件资源对接](https://docs.icourse163.org/api-doc/resource-intergration.html) | 面向采购课程资源、已有自有教学平台的客户，提供视频、可下载 PDF、客观题库 | 不是对全站所有公开课、SPOC、付费课的任意个人下载承诺 |
| [通用信息](https://docs.icourse163.org/api-doc/general-info.html) | 第三方系统激活后获 `appId`、`appSecret`、`aesKey`，请求签名；分钟请求量等有约束 | 不应误写为 `appKey`，也不能当成普通账号的 OAuth 自助 token。Cookie 与这些机构参数是两条不同路线 |
| [课程赋权列表](https://docs.icourse163.org/api-doc/get-info.html) | `/mm-open-api/open/courses/permission` 读取当前赋权学校云的 MOOC／SPOC，具体赋权需和交付运营确认 | “学校云课程列表”不等于任意学生的全部已选课程列表 |
| [期次与结构](https://docs.icourse163.org/api-doc/get-info.html) | 课程包含多个期次，已发布结构含章、lesson、unit，以及 homework／quiz／exam 目录等 | 目录记录不等于题干、选项、本人提交、批阅结果或未开放章节内容 |
| [客观题库](https://docs.icourse163.org/api-doc/get-info.html) | `/mm-open-api/open/course/questionsByTerm` 包含题干 HTML、选项等，选项对象可带答案标记 | 这是机构赋权题库契约，不是普通学生考试答案／本人批阅接口 |
| [成绩／进度](https://docs.icourse163.org/api-doc/get-info.html) | 期次总分、统计及学习进度等服务；调用依赖应用与对接用户身份 | 不能由学期聚合成绩推导全部题目逐题批阅、所有作答和教师评语可取 |
| [视频播放器 SDK](https://docs.icourse163.org/api-doc/video-info.html) | Web／H5 接官方播放器，凭视频 ID 和播放签名播放；可 pause／seek／getPosition，状态有字幕 URL／语言字段 | 不证明普通用户可获取播放凭证、可把加密流交给任意播放器，或可独立下载字幕和完整媒体 |

以上官方网页显示更新信息主要为 2026-03-21。通用信息把 `1002` 说明为一分钟超过 500 次的频繁请求，但资源方案又写更新间隔“不少于1小时(24h)”，原文存在歧义，不能自行改成统一轮询策略。[通用信息](https://docs.icourse163.org/api-doc/general-info.html)、[更新机制](https://docs.icourse163.org/api-doc/resource-intergration.html)

### 视频、字幕和正式学习状态分别核对

官方资源方案明确视频流已加密，需要其播放器 SDK；SDK 暴露播放位置与字幕字段，并不等于用户拥有可自由重放的稳定媒体直链。是否能截图、跨域读 video、下载或转换媒体，应按实际授权及播放器行为核查，本轮没有测试。

播放器事件、暂停和拖动方法的存在，也不能证明播放器从不联网或不产生业务上报。接入时若要保持学校学习记录与本项目进度分开，需要单独核验 SDK、课程状态与网络行为；研究不默认启用学习完成、计时上报、签到或答题提交。

### 学期、账号与付费边界

课程 ID、期次 ID／`tid`、章节 ID、单元 ID 应分开。官方介绍明确学习发生在期次中；某门课公开的课程介绍页不等于所有期次都开放，课程结束后访问由课程政策和教师设置决定。旧期缓存不得静默指到新期资源。[官方期次说明](https://docs.icourse163.org/api-doc/resource-intergration.html)

平台有收费课程和有效期，不能引用单门旧课程 FAQ 的“免费”推导全站免费；VIP／已购／试看／SPOC选课身份也不是同一种权限。付费并不自动意味着第三方工具能导出原件或适配其加密方式。[官方售后政策](https://www.icourse163.org/topics/After-sales-policy)

当前证据没有证明普通个人可以从官方接口自助读取全部选课、所有课件和逐题批阅；也没有证明所有对接都必须以同一种商业合同进行。后续须确认具体应用类型、课程赋权、学生身份绑定和数据用途，不能把技术 URL 当作已开通服务。

## MoocDownloader：README 与实际 resolver 有差别

README 声明可下载视频、课件、附件和字幕，流程为打开网页登录、输入课程链接、选择下载类型与清晰度。固定源码 `Course163Resolver` 实际使用浏览器中的课程／期次对象、会话 Cookie 和网页 RPC，不是官方机构 `appId/appSecret` 对接。[固定 README](https://github.com/MoocDownloader/MoocDownloader/blob/f36b7c24c1f30bead8d24f8af4bfce9ef0ccb446/README.md)

| 需求 | 固定源码能证明什么 | 缺口 |
| --- | --- | --- |
| 登录／课程选择 | 有网页登录会话；给定课程链接后读取 `courseDto/termDto`，再取期次章／课／unit | 没有由此证明可列出全账号已选课程、所有历史期次或学校SPOC；需用户权限与当前页面结构 |
| 视频 | 获取资源播放签名，再解析视频URL；按质量及 mp4／hls／flv偏好选择 | 解析分支存在不是2026可下载证据；HLS、加密、试看和付费内容均需分别验证 |
| 字幕 | 读视频接口 `Captions`，按字幕 URL 加入下载列表，文件名标语言及srt | 没有证明每视频都带字幕、字幕本来就是SRT或均有人工／AI身份；本轮没有下载核格式 |
| 课件 | Document分支读取 `textOrigUrl`，用下载URL中的文件名／扩展名保存 | 不是截图转PDF，但实际是否PDF／PPTX取决于服务端对象；不能承诺所有原始PPT均可取 |
| 附件／HTML富文本 | 有类型枚举，README有附件声明 | 主遍历实际只处理Video=1与Document=3；未见Attachment=4或通用HTML内容保存分支，不能写完整支持 |
| 作业／测验／考试 | 类和枚举中有Quiz、Exam、Homework等结构 | 结构名不代表已实现题目、本人提交或批阅导出。主下载分支未处理它们 |

上述判断均来自 [固定 Course163Resolver.cs](https://github.com/MoocDownloader/MoocDownloader/blob/f36b7c24c1f30bead8d24f8af4bfce9ef0ccb446/src/MoocResolver/Resolvers/Course163Resolver.cs)、[内容类型枚举](https://github.com/MoocDownloader/MoocDownloader/blob/f36b7c24c1f30bead8d24f8af4bfce9ef0ccb446/src/MoocResolver/Models/ICOURSE163/Coursewares/CoursewareContentType.cs)、[文档响应字段](https://github.com/MoocDownloader/MoocDownloader/blob/f36b7c24c1f30bead8d24f8af4bfce9ef0ccb446/src/MoocResolver/Models/ICOURSE163/Coursewares/CoursewareRemoteResult.cs)。

其 [#95](https://github.com/MoocDownloader/MoocDownloader/issues/95) 在2024-01-18报告视频下载失败、附件仍正常；[#93](https://github.com/MoocDownloader/MoocDownloader/issues/93) 在2023-12-04报告付费视频不能下载。它们是用户报告，不是本轮复现；结合2024最近源码，只能列为旧实现线索，不能保证当前兼容，也不能推断当前必然全部失败。

## 停维脚本的覆盖与风险

### SigureMo/mooc-dl

README 明确停止维护，登录只支持爱课程账号，且账号须已参加课程；配置类型1／3／4分别称视频、PDF、附件，可设置章节范围。源码的课程 URL 正则也接受 `/spoc`，但**接受链接不等于突破SPOC权限**。[固定 README](https://github.com/SigureMo/mooc-dl/blob/a37f0bf3ae33b237101bace68a9086d2ecb9144f/README.md)

固定 `mooc-dl.py` 会读取期次目录，用移动端资源接口取视频／字幕；PDF分支取 `textOrigUrl`。名为 `RICH_TEXT` 的类型4只在 `jsonContent` 呈现附件时取文件并走附件接口，不是保存所有HTML富文本。该实现还使用 `eval(unit['jsonContent'])`，说明不能将旧解析代码未经适配直接放进具备私有会话的正式执行层。[固定源码](https://github.com/SigureMo/mooc-dl/blob/a37f0bf3ae33b237101bace68a9086d2ecb9144f/mooc-dl.py)

作者README的非商业用途说明与GPL许可应分别保留供后续选型核查，本文没有完成分发许可审查。没有执行其共享账号、登录逻辑、下载或任何学习行为。

### wqmsybpw/icourse163_downloader

固定脚本要求人工输入 `term_id`、`STUDY_SESS`，拉课程章／课／unit、获取视频播放信息、下载HLS片段并合并。它是已归档视频脚本，不是课件、全部附件、通用HTML、作业批阅或全账号选课列表工具；也不因此取得正式个人API契约。[固定源码](https://github.com/wqmsybpw/icourse163_downloader/blob/8d0b5d858206a78d831820fa9e5eee7d1ab94268/main.py)、[许可说明](https://github.com/wqmsybpw/icourse163_downloader/blob/8d0b5d858206a78d831820fa9e5eee7d1ab94268/README.md)

## 不应误认的通用工具与独立客户端

you-get 的 [icourses.py](https://github.com/soimort/you-get/blob/049548f3f3f35e67ba8d3181c71fdc71d11cf260/src/you_get/extractors/icourses.py) 实际请求 `icourses.cn`；[netease.py](https://github.com/soimort/you-get/blob/049548f3f3f35e67ba8d3181c71fdc71d11cf260/src/you_get/extractors/netease.py) 是网易影音相关实现，不能只因网易品牌或“爱课程”名称算作中国大学MOOC连接器。

yt-dlp 固定 [extractor目录](https://github.com/yt-dlp/yt-dlp/tree/9b58cb33d0cd3e823c8d8732f6adce8faa1f37e3/yt_dlp/extractor) 中的 `getcourseru` 与 `neteasemusic` 也不是目标平台；本轮未核到专用课程／选课／PDF／测验提取器。某个授权媒体URL或公开嵌入可能适配 generic，仍须单独实测，不把目录未见专用模块扩大为所有目标URL必然失败。

“学无止”等独立客户端可作为产品声明候选。[作者官网](https://www.xuewuzhi.cn/icourse163_downloader)检索时列V2.19.64、2026-10-21，并声明按课程链接及期次选择、登录有权访问的账号、下载视频和课件。旧 PyJun 开源地址404不能由新版的版本号补足源码、SDK或可嵌入授权。本轮没有核验其二进制、账号行为、内部解析或对外SDK；不把客户端宣传支持直接当成本项目接口依赖。

## 能力收口与后续问题依据

| 学习动作 | 本轮最可靠边界 |
| --- | --- |
| 登录后选取已选课、期次、章节 | 官方机构方案有赋权课／已发布期次结构；个人会话旧工具以给定链接为主，未证明全部已选课完整浏览 |
| 导入PDF课件 | 官方合作接口明确可下载；旧工具有取原下载对象线索，但当前个人资格与完整性未验证 |
| 导入视频与字幕 | 官方加密视频需SDK；旧工具有视频／字幕分支，不能保证当前个人权限、格式、字幕覆盖或完整媒体 |
| HTML富文本、混合附件 | 不等同PDF；已核工具覆盖不足，类型枚举或RICH_TEXT命名不能作全覆盖证据 |
| 读取作业题目、选项、本人答案与批阅 | 官方题库／目录／聚合成绩并非同一个对象；本轮没有成熟个人通路的完整证据 |
| 本项目做练习，学校正式计分 | 可以作为待讨论方案，仍未确认；不能把下载工具附带的学习记录／答题提交自动接进来 |
| MCP与Harness接入 | 没有核实成熟、经维护且只读范围清晰的专用MCP；可封装旧库不等于已有可交付组件 |

后续应分别确认连接路径、用户选取范围、期次版本、原件与派生内容、正式提交去向。研究建议不替代用户决定；本轮不默认打开整课扫描、刷进度、题库答题或向模型发送整课资料。

未覆盖：2026真实账号与SPOC兼容、学校与课件权限、VIP／试看／DRM、目录完整性、富文本／公式保真、字幕实际格式与时间轴、附件版本与失败恢复、播放器业务上报、受控截图、题目及批阅导出、取消和未知结果对账。本次形成本报告并补充研究导航，不修改正式需求、配置、代码或账号数据。
