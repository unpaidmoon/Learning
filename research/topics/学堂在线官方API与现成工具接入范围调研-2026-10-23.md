# 学堂在线官方 API 与现成工具接入范围调研

检索日期：2026-10-23。目标是 `xuetangx.com` 公共课平台及其历史／当前网站；学校学堂云、雨课堂租户分别辨认。用户本轮要求调研后一次给完整方案供确认；本文是证据和方案依据，不是正式需求、MVP变更或实施授权。

本日后续：用户明确“全部接受”，要求将完整方案写入[学堂在线正式接入需求](../../docs/product/学堂在线接入需求收口-2026-10-23.md)，先不开发。已确认公共平台与学校入口分开、业务只读、手动选择、视频／字幕／资料／课后题目及变化提醒，并明确排除公告／大纲／评分标准／考核时间／讨论等。下文“待确认”按研究形成时理解，产品范围以后续收口为准；源码能力不自动全部采用，账号响应、权限和副作用仍未实测。

## 证据范围与主要判断

本轮读取官方公开页面与指南、作者 README、固定 SHA 源码、GitHub live 状态及发布信息。没有安装工具、登录、取得私人 Cookie、请求真实媒体、报告学习进度、答题、调用模型或执行任何下载脚本。

找到的开源工具能够解释若干技术路线，但主要源码停留在2017—2022年；目前没有本项目验证通过的现成全覆盖连接器。视频、无时间轴字幕文本、PDF、HTML讲义、题目与本人批阅是不同对象，不能用“支持学堂在线下载”一概代替。

官方网页内部接口不等于正式对第三方开放的API；关联组织历史仓库不等于当前公共MOOC个人授权契约。工具 README、源码、发行制品与本项目实测分别标注，不编使用率或成功率。

### 当前官网公开前端有业务接口线索，仍不是第三方授权文档

官网匿名HTML引用的 [courseAction公开bundle](https://fe-static-yuketang.yuketang.cn/fe/static/xt/1.6.374/xtassets/src_api_courseAction_js-src_views_layout_Layout_vue_ebfcf850dab53a19e6f7.js) 静态阅读可见下列封装。该制品为72051字节，SHA-256 `797de4a3a13f033e9531d03d40c175f1199eff289916b10c273b2b51bda7973d`；仅取公开JS，未调用任何列出的业务接口。路径是源码中的相对路径／片段，实际baseURL前缀未核，不自行拼造完整请求。

| 当前静态源码线索 | 研究边界 |
| --- | --- |
| `course_chapter` GET `xtbase + 'learn/course/chapter'`；`getDetailByLeafId` GET `learn/leaf_info/{classroom_id}/{leaf_id}/`，带sign | 当前前端存在课程／leaf读取封装；不是全部账号课程、SPOC或所有期次可取的证明 |
| `getAllExercise` GET `exercise/get_exercise_list/{exercise_id}/{sku_id}/`；`getAnswerSheet` GET `exercise/get_answer_sheet/{leaf_id}/` | 有练习和答题页读取线索，但未核响应字段、本人答案、教师反馈、题型和权限，不能直接称完整批阅导出 |

## 固定源码能力与缺口

### next视频下载：ritou11/xuetangxd

README要求账密或RSA处理后的口令，以及课程链接中的cid／sign。`lib/reg.js` 使用next域名，登录调用网页`/api/v1/u/login/e_p/`，再读取用户基本资料；章节走LMS接口。代码注释列附件／习题类型，但遍历实际只收 `leaf_type===0` 视频，取leaf信息中的CCID及playurl，再下载视频。[固定README](https://github.com/ritou11/xuetangxd/blob/e9a2cc1236679c0c8335b1c1138ee95119608cf8/README.md)、[协议封装](https://github.com/ritou11/xuetangxd/blob/e9a2cc1236679c0c8335b1c1138ee95119608cf8/lib/reg.js)、[主流程](https://github.com/ritou11/xuetangxd/blob/e9a2cc1236679c0c8335b1c1138ee95119608cf8/index.js)

| 可确认 | 尚无依据 |
| --- | --- |
| 已知cid／sign时读课程章节；视频leaf过滤；下载链接缓存与视频下载 | 完整“我的课程”浏览、所有历史期次、学校SPOC与已购资格映射 |
| 登录POST和之后的章节／leaf／播放信息GET明确可分辨 | 官方OAuth、独立最小scope、后台零业务副作用保证 |
| 获取两种quality来源并取其中一个URL | 原始多音轨、字幕、PDF／附件／HTML、题目和本人批阅导出 |

其登录和私有会话处理是2021实现，参数中出现`appid=10000`不等于本项目获发机构应用凭据。源码能列出URL也不证明是完整、未过期且可由任意播放器处理的媒体。

### 旧课程结构：Foair/course-crawler

固定 `mooc/xuetangx.py` 用Cookie检测旧登录状态，读取旧课程about／courseware页；可从PDF书架元素获取PDF电子书，把讲义区域保存为`Handouts.html`，遍历旧标签／视频组件，并读取字幕翻译列表／下载接口。视频分支经`videoid2source`产生链接和命名／播放清单。[固定学堂在线实现](https://github.com/Foair/course-crawler/blob/3d8f055611119a9d9c46e17dd1b9c764603b5cb9/mooc/xuetangx.py)

这里“HTML讲义”是从旧页面区域序列化出来的内容，不保证图片、公式、外链资源均可离线；PDF电子书也不等于教师原始PPT。旧字幕接口导出的SRT与新平台字幕文本是不同路线。不能以该文件包含`PDF/HTML`分支就写成当前next完整支持。

项目README明确不再更新，并推荐过其他项目；被推荐项目的旧地址、当前商业客户端或重打包程序，不能继承该仓库的可验证源码身份。[固定README](https://github.com/Foair/course-crawler/blob/3d8f055611119a9d9c46e17dd1b9c764603b5cb9/README.md)

### 浏览器DOM提取：ShenHongFei用户脚本

固定脚本只匹配旧`/courses/**`页面，从`.xt_video_player`取视频src、从`transcript/download`链接取字幕，按DOM课程／章节文本命名，添加下载按钮并可发送aria2 JSON-RPC。它将当前网页Cookie作为请求头交给本地aria2。[固定实现](https://github.com/ShenHongFei/xuetangx-aria2-download-userscript/blob/d51dbaa71f5ede3b7483f90a138e336c59cda656/src/index.ts)

这是2017旧页脚本，不是新站目录API、全账号课程选择器或跨租户SDK；也没有PDF、附件、题目与批阅的对应分支。其本地下载服务、凭据转交和浏览器页面读取范围要另行封装，不能把整脚本直接暴露为Harness任意网页操作。

### 新平台字幕文本：lynzrand/xuetangx_sub

固定实现用`sessionid/sign/cid`查询章节和视频leaf，再按媒体ID请求`subtitle_parse`。它只保留返回的`text`数组，按行写`.txt`，没有保留时间码或生成SRT／VTT。[固定readme](https://github.com/lynzrand/xuetangx_sub/blob/e111f1bbaad26fc7e9a56cb58f5089ee78240ad4/readme.md)、[固定main.py](https://github.com/lynzrand/xuetangx_sub/blob/e111f1bbaad26fc7e9a56cb58f5089ee78240ad4/main.py)

因此可作为字幕文字获取思路，不能直接交付同步字幕、原文逐句时间回跳、人工／AI来源判别或全语言字幕覆盖；没有字幕时也不提供ASR。视频、音轨、课件和作业均不是它的输出。

## 完整方案的待确认依据

可据现有证据向用户一次提出以下完整方案，而非逐项追问：公共学堂在线与学校学堂云分入口；用户在目标平台登录后选定已有权限的课程／期次／章节；先明确能识别的目录和资源，按对象保存视频、原始可下载文件、HTML派生内容或字幕文字，并标出覆盖与缺失。当前不承诺全部资源或直接使用停维脚本。

本项目自己的观看位置、笔记、练习和AI问答，与学校计分／平台正式作答状态分别设计；是否写回、范围多大、正式提交去向仍由用户一次确认。模型只读取用户确认的资料范围；跨课程、全课扫描、网页画面、后台下载与外部发送边界不能由连接成功自动扩大。

上述为待确认建议，不是已决定方案。技术选型还需固定可交付制品或实现窄适配层，再按真实授权输入验证；不在研究阶段开发、登录或调用模型。

未覆盖：当前用户平台版本／租户、登录与Cookie有效期、机构凭据申请、我的课程完整性、历史期次／已购／SPOC、课件与HTML保真、字幕时间轴、媒体加密／试看／音轨、逐题批阅、访问副作用、取消恢复及源版本对账。本次形成本报告并补充研究导航，不修改正式需求、MVP、代码或配置。
