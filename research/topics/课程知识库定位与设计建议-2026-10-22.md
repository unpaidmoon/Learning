# 课程知识库定位与设计建议

日期：2026-10-22。性质：结合官方一手资料、当前工程与本聊天最新决定的研究建议。用户随后指定重点参考 [HKUDS/DeepTutor](https://github.com/HKUDS/DeepTutor) 与 [DeepStudent](https://deepstudent.cn/)，两项目的具体借鉴见第 3.1 节。仅新增本报告；未改需求、契约、计划状态或应用代码，未导入用户讲义或运行模型、OCR、ASR与检索测试。

## 1. 推荐定位

**把课程知识库定位为：按课程组织、可搜索和引用、能返回原文的学习资料基础。** 它承接“资料很多、记不清知识点在哪、希望对照多份解释”的问题，让阅读成果可重复利用。回答仍由 Harness 原有聊天完成。

建议先做可靠的课程资料查阅与引用，再让同一索引为 Harness skill 提供只读检索能力。资料索引、个人知识沉淀和学习复习是不同层次；本轮不以知识库为由启动独立笔记、素材库或复盘系统。

## 2. 最新决定与尚未决定的范围

本聊天最新明确决定优先于旧文档中“每题按需补充字幕／资料”的表述：

- AI 对话沿用 Harness 原有功能；应用不在每次发送前自动查资料或字幕、预先塞入正文。
- 字幕读取做成 skill，使用 Harness 原生机制：模型按名称与描述匹配后加载，用户也可显式调用。读取本次问题时间戳附近字幕；本地转写、暂停、持久保存与手改保留。
- 资料当前手动加入对话；后续知识库建立索引，具体用途和接入仍在讨论。本报告的双入口、知识库 skill 与分期均是建议。
- PDF 阅读已确认文字层／扫描 OCR 选字、跨页选择、多区域图片引用和独立翻译。翻译只发送所选内容；OCR 当前页优先、后台逐步处理整份，可暂停并保存复用。整篇英语文章与题目自动分片暂不做。
- 自动找题继续取消；默认当前课程，跨课程需明确指定。不得补视频画面；资料未命中不自动联网。聊天、截图、学习行为不默认进入课程资料索引。

因此，**有索引不等于每轮自动检索；能检索不等于把整份资料发给模型。** 是否让知识库 skill 进入模型可调用目录，仍须用户确认。

项目依据见[需求总结](../../docs/product/AI辅助学习项目需求总结.md)、[应用契约](../../docs/architecture/应用契约.md)、[技术选型](../../docs/architecture/AI辅助学习项目技术选型方案.md)及[旧知识库用途调研](知识库常见用法与学习场景价值调研-2026-10-20.md)。旧文件尚未同步本聊天新决定，不能据其旧检索规则实施。

### 3.1 用户指定的两个项目：具体借鉴与取舍

本次核对的 DeepTutor 源码提交为 `a31d82624c27d75f4e771d4fcb78dce16470b383`，DeepStudent 为 `635216503c0b34bdf812e17942e0f09f51872e6f`，均为 2026-10-18 的提交。官网说明、源码路径与实际运行效果分别看待：本轮未安装或运行两者。

**DeepStudent 主要提供贴近本项目的学习流程参照，DeepTutor 主要提供资料检索工程的参照。** 它们都比单纯的向量索引更完整，但完整产品功能不等于本项目应照单采用。

| 可借鉴点 | 查到的具体依据 | 本项目怎么用 |
| --- | --- | --- |
| 资料、阅读与引用共用来源身份 | DeepStudent 阅读器将选区文本快照、`sourceId` 与 `page:N` 定位加入结构化上下文；注释明确旧整文档引用曾让模型拿到整本书，现改为选区上下文。见[选取接入代码](https://github.com/helixnow/deep-student/blob/635216503c0b34bdf812e17942e0f09f51872e6f/src/features/pdf/components/PdfSelectionActions.tsx#L216-L244)。 | 接受“选了什么就引用什么”，叠加本项目的来源版本与精确区域；不另存一套无回链的摘录文本。 |
| 把索引可用性展示给用户 | DeepStudent 文档给出待索引／索引中／失败／不适用／已索引、单项重试更新，以及召回测试入口。见[资源库文档](https://deepstudent.cn/user-guide/learning-hub)。 | 文件列表放简短状态，详细进度与失败原因按需查看；测试能否找到实际片段，不以向量数量作为学习价值。 |
| 索引构建能恢复、验证后发布 | DeepTutor 区分每文档阶段进度与整库可查询状态，解析缓存绑定来源字节和解析参数，候选索引加载与探针通过后发布，失败保留旧可用版。见[恢复设计](https://github.com/HKUDS/DeepTutor/blob/a31d82624c27d75f4e771d4fcb78dce16470b383/docs/INDEXING_RECOVERY.md)。 | 复用本项目持久队列和来源版本规则，实现暂停／故障／重启后继续，避免源文件已变化却发布旧结果。 |
| 引用携带可检查的源页身份 | DeepTutor `SourceRef` 包含文档、来源摘要、页序和页标签，读取时检查源摘要，并区分可搜索、需 OCR 与无法定位。见[源页代码](https://github.com/HKUDS/DeepTutor/blob/a31d82624c27d75f4e771d4fcb78dce16470b383/deeptutor/services/rag/source_pages.py)。 | 返回资料身份＋版本＋页码／区域，来源失效时明确说明；不靠文件名和搜索排名反推来源。 |
| 检索与回答分开验证 | DeepTutor 普通 LlamaIndex 搜索路径返回检索片段及来源；其评测以查询与金标准原文段落检查召回。见[搜索实现](https://github.com/HKUDS/DeepTutor/blob/a31d82624c27d75f4e771d4fcb78dce16470b383/deeptutor/services/rag/pipelines/llamaindex/pipeline.py#L271-L335)和[评测数据结构](https://github.com/HKUDS/DeepTutor/blob/a31d82624c27d75f4e771d4fcb78dce16470b383/deeptutor/services/rag/eval/dataset.py)。 | 先证明选定数学／英语样例能找到正确原段，再验证 Harness 能据此回答；不额外增加“检索模型先答一遍”。 |
| 字幕成为可回看的来源 | DeepStudent 文档展示时间戳字幕、搜索、点击跳转与播放高亮；音视频是同一资源库的专用视图。见[音视频文档](https://deepstudent.cn/user-guide/media)。 | 借鉴字幕与播放器回看关联；本项目保留时间戳附近的字幕 skill 边界，不自动升级为整课字幕搜索。 |

源码同时暴露了不能直接照搬的行为：

- **DeepTutor 有自动找题分支。** 普通搜索入口会先解析查询里的题号并尝试查题，见[入口代码](https://github.com/HKUDS/DeepTutor/blob/a31d82624c27d75f4e771d4fcb78dce16470b383/deeptutor/services/rag/pipelines/llamaindex/pipeline.py#L278-L294)。这与本项目明确取消自动找题冲突，应只参考检索、来源和恢复模块。
- **DeepStudent 的检索策略比本项目宽。** 其知识检索 skill 将资料、页面图像和用户记忆统一搜索，支持主动检索开关，并写有本地不足时网络补充的策略。见[技能定义](https://github.com/helixnow/deep-student/blob/635216503c0b34bdf812e17942e0f09f51872e6f/src/features/chat/skills/builtin-tools/knowledge-retrieval.ts)。本项目保留当前课程与明确外部需求边界，触发继续使用 Harness 原生机制，不搬其默认策略或技能管理器。
- **翻译的上下文边界不同。** DeepStudent PDF 组件向翻译浮层传递选区前后文，见[相关代码](https://github.com/helixnow/deep-student/blob/635216503c0b34bdf812e17942e0f09f51872e6f/src/features/pdf/components/PdfSelectionActions.tsx#L144-L151)。本项目已明确翻译只使用选区，因此最多借鉴入口与原文回链，不能照搬这条数据链。这里只确认组件传参，未运行捕获其实际出站。
- DeepStudent 的自由桌面多窗口、可写笔记／题库／卡片、自动使用关键画面生成讲义，以及 B 站导入均超出本轮范围；涉及视频画面还与本项目提交范围规则冲突。其[阅读文档](https://deepstudent.cn/user-guide/reading-translation)也包含整页引用、全文翻译等不同范围，不应因“已有现成实现”自动加入。

本次核对到 DeepStudent [LICENSE](https://github.com/helixnow/deep-student/blob/635216503c0b34bdf812e17942e0f09f51872e6f/LICENSE)为 AGPL-3.0，DeepTutor [LICENSE](https://github.com/HKUDS/DeepTutor/blob/a31d82624c27d75f4e771d4fcb78dce16470b383/LICENSE)为 Apache-2.0。当前建议是参考设计与小模块边界；复制具体代码前还应核其文件及依赖许可和实际版本。DeepStudent 的 Rust/Tauri 与 DeepTutor 自有运行层也不作为更换 Harness 主线的理由。

## 4. 最值得服务的学习任务

| 用途建议 | 示例 | 价值与边界 |
| --- | --- | --- |
| 找课程里的知识点讲解 | 搜索“闭区间连续的条件” | 返回讲义原文及页码，减少翻文件；不恢复按题号／题意找原题。 |
| 按课程的表述回答 | “这份讲义怎么解释可微与连续的关系？” | 依据指定资料回答，区分原文结论与模型解释。知识库 skill 接入尚待确认。 |
| 对照已选资料 | “比较教材和课件对这个定理条件的表述” | 同时保留各来源，不把互异条件拼成一个不存在的定理。 |
| 用户主动归纳 | “整理我选的这一章的定义、条件与易混点” | 先明确章节范围和处理覆盖；少量搜索命中不能冒充整章梳理。 |
| 后续自测与复习 | “根据已选资料出几道概念判断题” | 属于未来用户主动请求的候选；不自动生成卡片、复盘或后台摘要。 |

建议知识库首批以前三项为价值目标。整章归纳需要增加按范围枚举与覆盖核对，再逐步交付；它与局部相关片段检索的完整性要求不同。

字幕暂按附近时间窗 skill 独立提供。将整课字幕加入全局知识库，以便“找出全课何处讲过某概念”，属于新增用途，须另行确认，不能从“知识库必要”自动推出。

## 5. 产品形态与信息分层

建议继续使用“课程目录／资料阅读／Harness 聊天”三栏，课程文件列表显示资料是否纳入检索、处理进度和失败状态，提供一个课程资料搜索入口。命中项显示资料名、页码和原文摘录，可打开原页或加入现有草稿；不另建知识库专属聊天。

底层分为三层：

1. **来源层**：原 PDF、讲义、课件及其课程关联、稳定身份与版本。原件原地引用，索引不复制成另一套文件目录。
2. **可检索层**：复用阅读器已得到的文字／OCR结果，按段落与章节保存文本、页码和坐标，再建立可重建索引。搜索排名或机器生成摘要不成为原文事实。
3. **使用层**：人工搜索与可选知识库 skill 共用受限检索服务。个人笔记若以后获授权，再成为显式来源类型；历史聊天不会自动转成“知识”。

“资料纳入知识库”建议作为可见的课程来源状态，避免再做繁重的二次导入界面。用户可排除资料；草稿中临时上传的文件不自动永久纳入课程知识库。具体默认纳入规则仍应随最终范围收口。

## 6. 与 Harness 的接法

推荐流程：`课程来源 → 本地文字/OCR与索引 → 受限搜索/读取 → 人工引用或 Harness skill → 原有聊天回答 → 回到原文`。

原生 skill 的名称／描述用于发现和触发，指令解释何时查、如何解释结果；实际资料访问由项目只读接口执行，核课程、来源版本、片段范围、返回量和取消。skill 本身不能替代执行权限。也不需要为了读讲义开放通用文件系统或 shell。

已核对项目锁定的[官方参考源码](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/skill/tool-skill/README.zh.md)：支持模型按目录加载和用户 `/name`。但这是原生能力依据，不是项目运行组合已接通的证明。

当前[学习 profile](../../harness/profiles/learning.patch.json)禁用了 skill 发现／加载，[执行 guard](../../harness/plugins/learning-guard.mjs)采用工具拒绝策略；[后台依赖](../../backend/pyproject.toml)也未形成课程检索实现。已有来源版本和文件关联基础可复用，后续需新增受限能力并做固定制品兼容与输入范围验证。不能声称放入 `SKILL.md` 就已可用。

## 7. 实现与分期建议

**首批形成完整闭环**：复用 PDF 阅读/OCR产物，先支持 PDF、TXT／Markdown 的课程来源、索引状态、人工搜索、精确页码引用与回看；若用户接受知识库 skill，同批接入原有 Harness 对话，避免只交付一个无实际用途的后台索引。Office 随其格式转换能力接入，共用来源和索引链。

**检索效果逐步补强**：目标同时覆盖术语准确匹配和“换一种说法”的自然语言问题。先用少量固定样例比较关键词与关键词＋本地语义召回；正式组合按结果选择。SQLite 全文检索和本地语义索引可沿用项目已有候选，不提前固定所有库、下载模型或另建独立服务。

**后续任务复用**：在来源和覆盖可靠后，再提供用户指定范围的章节归纳、多资料对照及主动自测。笔记、素材积累、跨课程知识图谱与复盘仍需各自授权和需求讨论。

数学资料优先保证原页、原段和条件可回看。OCR得到可选英文文字，不证明分式、上下标、矩阵与图形语义已完整解析；公式图片问答仍沿用用户框选。初期不能承诺纯公式相似检索，不能用缺失负号或假设的片段生成肯定结论。

## 8. 需要用什么验收

建议以实际学习任务为判据，而非“有多少向量”或“索引成功”：

- 同一知识点能用原术语和自然语言改述找到相关原段；分别记录命中与漏检索。
- 词义相近但条件不同的定理能区分，引用含必要假设，章节切段不截掉条件。
- 每条命中能打开对应版本的原页／区域，原文与模型解释可核对。
- 扫描件部分处理时报告覆盖范围；未处理、失败、索引过期与已处理未命中分开。
- 资料同名替换后不混用版本，旧聊天保留原引用内容；排除或失联来源不再参与新检索。
- 普通截图问题没有应用层预检索；若采用知识库 skill，原生触发后的实际读取范围可核。
- 默认仅当前课程；跨课读取、视频补帧、任意路径及未允许来源均被执行层拒绝。
- 暂停、退出和重启可复用已提交结果；OCR／ASR／索引并行时播放、截图、当前问答仍可用。
- 对“总结整章”核范围清单与未覆盖内容，不能用几个命中片段宣称完成全章。
