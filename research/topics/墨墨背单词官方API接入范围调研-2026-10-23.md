# 墨墨背单词官方 API 接入范围调研

检索日期：2026-10-23。本文核对官方公开OpenAPI、帮助、授权与产品语义，区分云词本、学习规划、内容读写和Markji，为随后grilling提供依据。仅研究，不代表接入已实现、应用已审核或需求已确认。

本日后续：用户已逐项确认并要求收口，[正式墨墨接入需求](../../docs/product/墨墨背单词接入需求收口-2026-10-23.md)为产品范围主要来源，先文档、不开发。下文“建议／尚待确认”保留研究形成时含义，已获确认的筛选、画像、写入及正式复习边界以后续收口为准；接口证据仍不等于真实账号验证。

## 主要结论

1. 墨墨背单词有正式公开API，可做云词本管理、按拼写／ID查询词汇、管理本人创建的释义／例句／助记，以及部分公测学习数据读写。无需将旧逆向接口当成唯一方案。
2. “收进云词本”“加入实际学习单词”“提前到现在复习”是不同动作。云词本成功不等于学习队列成功；加词结果受已有状态与词数上限影响。
3. 当前公开规范的背单词学习接口只有进度、今日单词、学习记录查询、加词和提前复习五类，**没有列出提交认识／模糊／忘记等逐题反馈或完成复习的操作**。读到反馈字段不代表能回写。
4. “获取单词”基础返回是ID与拼写；释义／助记／例句的GET明确限定“自己创建”的内容。不能据功能介绍中的“查词”将其扩大为免费、全量官方词典或公共内容库访问。
5. 学习接口标公测，部分依赖当天先打开App初始化和自动同步；不能保证第三方工作台脱离App独立运行完整官方背词流程。官方网页版复习是另一个需要资格与实际验证的入口。
6. Markji是另一产品，公开接口主要管理已有自建牌组下的章节、卡片和文件，不等于墨墨背单词学习规划。平台版权内容另受审核与用途限制，API存在不等于可永久保存到课程知识库或任意送入模型。

## 背单词API支持范围

| 能力组 | 当前公开契约 | 重要边界 |
| --- | --- | --- |
| 查询词汇 | `GET /api/v1/memo/vocabulary`按spelling查；`POST /api/v1/memo/vocabulary/query`按拼写或ID批量查 | `Vocabulary`只有id、spelling；批量最多1000，查询条件互斥。不是修改公共词库或取得全部词典正文 |
| 云词本列表与详情 | `GET /api/v1/memo/notepads`；`GET /api/v1/memo/notepads/{id}` | 列表有limit／offset／ids筛选；详情含原content、解析后的章节／单词列表和更新时间 |
| 创建／更新／删除云词本 | `POST /api/v1/memo/notepads`；`POST/DELETE /api/v1/memo/notepads/{id}` | 创建／更新包括status、content、title、brief、tags。没有独立原子“追加一词”接口；更新须防止覆盖既有内容或用户修改 |
| 自建释义 | `GET/POST /api/v1/memo/interpretations`；`POST/DELETE /api/v1/memo/interpretations/{id}` | GET仅本人创建的释义；创建关联voc_id，包含标签与发布状态，不代表可改官方标准释义 |
| 自建助记 | `GET/POST /api/v1/memo/notes`；`POST/DELETE /api/v1/memo/notes/{id}` | GET仅本人创建的助记；包含note_type、note及状态，非通用课程笔记系统 |
| 自建例句 | `GET/POST /api/v1/memo/phrases`；`POST/DELETE /api/v1/memo/phrases/{id}` | GET仅本人创建的例句；创建含voc_id、例句、译文、标签、origin来源。可关联用户选定原句，但不是自动读取或发送整页的授权 |
| 今日学习进度（公测） | `POST /api/v1/memo/study/get_study_progress` | 返回finished、total和毫秒时长；当日未打开App初始化时总数可能不准确，需要自动同步 |
| 今日学习单词（公测） | `POST /api/v1/memo/study/get_today_items` | 可筛完成／新学，或按拼写／ID；包含顺序、是否完成和部分反馈。最多前1000，默认50；当日未初始化可能无法取得 |
| 学习记录查询（公测） | `POST /api/v1/memo/study/query_study_records` | 有加入／首次／最近／下次日期、最近反馈、每日最多一次的学习次数等；按日期／词／标签查询，可只取计数；默认50、最多前1000，不是无限全历史事件导出 |
| 加入学习单词（公测） | `POST /api/v1/memo/study/add_words` | 使用查询得到的词ID，单次最多1000；`advance`控制是否一并提前复习。响应是实际added_count，重复或上限不足可能部分添加 |
| 提前复习（公测） | `POST /api/v1/memo/study/advance_study` | 最多1000个词ID，实际advanced_count可能小于请求数；独立提前复习要求10级。加词接口的advance参数另标无等级限制，不混为同一条件 |

上述路径均来自同一官方快照。内容管理的具体权限与内容使用范围还需结合下文授权和服务协议；有删除接口不代表本项目默认自动删除平台资产。

## 对本项目的研究建议，尚未确认

- 阅读收词的最小闭环可以是：用户选词→匹配墨墨词ID／词形→写到指定云词本→保留本地来源位置→核对实际结果。需要同时加入学习规划时，用另一个明确动作或明确设置决定，不能把收藏偷偷变成新增学习任务。
- 原句、译文、助记写入是额外出站内容。词本只需所选词／短语，不应为收一个词自动上传相邻句、整页或全文；用户明确选定的原句可按自建例句接口另行保存。
- 云词本更新要求较完整字段，应读取并合并既有内容、保留用户修改，不能用旧快照覆盖。规范没有提供通用原子追加／幂等键保证，本项目仍须去重、保存实际回执、处理部分成功和未知先对账。
- 需要学习看板时先展示实际返回的进度与单词清单，标明同步／初始化缺口；不能把本项目练习、AI推断或本地卡片评分写成墨墨官方学习完成。
- 查词界面显示平台内容、本人自创释义、用户原文和AI解释是不同来源。版权内容的缓存／模型处理依授权确认，不把其默认纳入长期课程知识库；用户原始资料与本项目自创成果继续有独立身份。
- 本次只核能力，不继承学习通“只读”到墨墨，也不把原先“生词写入目标”扩大成已批准全部账号CRUD。接入动作、目标对象与学习安排由接下来的grilling逐项确认。

本轮研究不改变B站第一个接入、各平台分别验收及当前13场景交付范围，不修改正式需求或MVP工作包状态。

## 证据与验证范围

### 补充核查：词汇水平、全库读取与读后推荐

用户进一步明确希望长期记忆，并询问能否让AI结合已有词库与水平，在读完一篇后整理值得加入且不重复的词。以下为可行性分析，尚未确认具体触发、去重范围和写入流程，不构成实施授权。

本次重新无token读取官方YAML，SHA-256仍为上文快照值，规范未发生变化。进一步核对如下：

| 问题 | 证据结论 |
| --- | --- |
| AI能否了解用户词汇水平 | 可读取单词对应的学习次数、首次／最近／下次学习日期、最近认识／模糊／忘记反馈与熟知等标签，作为部分掌握证据。它不是校准词汇量测试，不提供完整CEFR／考试等级结论；没在墨墨出现的已知词也不在这些记录里 |
| 能否读完已有云词本内容 | 列表有limit／offset，可分页取得接口授权可见词本，再按id读取content与解析list。不能保证覆盖所有共享收藏词本、官方词书或全部公共词典；实际可见范围仍须账号验证 |
| 能否读全部学习记录 | 普通查询默认50、最多前1000，没有在该操作列出通用offset。不能把一次结果当全量历史。读后筛词可按本篇候选拼写或ID定向查记录，避免依赖全量导出 |
| 没有学习记录是否表示不认识 | 不能。可能没加入墨墨、已经移出并清除记忆数据、词形不匹配、同步／权限／获取有缺口；状态应为未查到或未知，不自动判生词 |
| API能否自动判断值得记 | 不能直接给出。长期学习价值由模型结合文章语境、复现、考试／专业目标及用户实际查词或明确反馈判断；算法判断应说明依据，不把一次查询变成已掌握结论 |

依据：[官方规范](https://open.maimemo.com/api_bundle.yaml)、[云词本词形规则](https://memodocs.maimemo.com/docs/QKUlwb6qTiLtzvk49BGc1ZVFnqg)、[移出记忆与数据清除](https://memodocs.maimemo.com/docs/KE8ZwhQ8UikDpKkeEggcKYgcnsd/)、[设备同步说明](https://memodocs.maimemo.com/docs/TJDKwbRRfi1prCktSXPcDQjrnJf)。

建议候选流程：用户明确选择文章与读后整理范围→AI提出候选词／短语并说明价值→按词形与墨墨词ID匹配→程序对照可读云词本、本篇重复、已有学习规划及本项目待加入记录→只向模型提供本篇相关的实际学习状态→生成可审阅清单→用户选定后按已确认的写入规则执行。程序负责确定性查重与状态校验，不能仅让模型凭对全词库的记忆去重。

可以区分“未收录的新词候选”“已收录但近期遗忘／模糊，建议巩固”“已收录或有熟知证据，默认不新增”“查询或覆盖未知，不能保证不重复”。已有词的新义／搭配可保留本篇语境，不自动重复创建同一个学习词。具体分组和默认筛选仍待用户确认。

去重范围和最新程度必须可说明；查询失败、云词本未读完或App尚未同步时，不能承诺全库无重复。写入前再次核对、部分成功与未知先对账属于后续实现约束，本轮未执行。

用户授权的词表／学习状态分析，与获取平台版权释义语料是不同用途。[官方开发指南](https://memodocs.maimemo.com/docs/open/)本身举出结合AI分析学习数据、辅助记忆的场景；不能把版权内容条款一概扩大为禁止AI理解用户学习状态。反过来，也不能借此把平台版权释义／例句全量发送给模型或永久入库。本方案可主要利用用户选定文章、词ID／拼写和相关个人学习状态，平台内容若需要另按其实际授权用途处理。

本轮只读取官方公开帮助、服务协议、演示页面与 OpenAPI 文档，没有登录、申请应用、使用私人 token、发出账户读写请求或运行 SDK。文档声明的接口存在，与本项目账号可以使用、申请权限成功和实际数据正确是不同验证层。

官方动态页面多数未标明确发布日期，统一记录检索日期；2026-07-09 的 Markji 答疑等可辨认发布时间的来源单列。网页正文可能以后更新，不能把本次页面当永久冻结协议或已验证稳定契约。

### 云词本解析不会原样保留所有输入词形

官方云词本帮助说明：默认模式先拆分单词，按换行保留短语；章节模式使用半角 `#`；首行 `//` 开启原型提取，例如 `saw` 可以提为 `see`。大小写也受墨墨词库匹配规则影响。5.5.30 以上版本还有新建、搜索、分享等入口变化。[云词本官方帮助](https://memodocs.maimemo.com/docs/QKUlwb6qTiLtzvk49BGc1ZVFnqg)

因此，“提交阅读原文”“保存一个生词词本”“匹配到多少词”“成功加入多少学习单词”至少是不同结果。不能只以请求成功就显示原文全部词语都已按原样加入学习。这里未实际创建词本或验证解析结果。

| 对外分发第三方应用 | 开发者须有绑定手机号的墨墨背单词账号，创建应用、填写用途和授权范围、提交审核；其他墨墨用户登录后授权应用 | 个人 token 的可获取性不等于应用审核通过，也不应把第三方产品设计成默认索取所有用户的私有凭证 |

第三方后端应用采用 OIDC Authorization Code，纯前端应用采用 OIDC PKCE；授权使用 `openid`、`profile` 和审核批准的 scope。应用主页需已上线的 HTTPS 页面并与登录回调同域；开发指南没有在公开正文穷举所有可申请 scope，而是让开发者以申请页面为准。同一用户在不同应用里的 `sub` 不同，不能拿它充当跨应用通用账号标识。限流主体是 access token 对应的被授权用户，按该用户跨应用合并计算。[官方开放平台](https://memodocs.maimemo.com/docs/open/)

个人凭证与第三方授权应分别评估。官方服务协议 5.1.6 对向服务用户索取身份验证凭据设有限制；这与官方提供个人开发入口同时存在，不能仅凭前者否定个人 API，也不能仅凭后者推导对外应用可绕过正式授权流程。[服务协议](https://memodocs.maimemo.com/docs/open-terms)

## 请求额度、词数与学习安排

### 查词、翻译与收费的补充核查

- “按拼写查词”操作返回词ID和拼写；释义、助记和例句的GET描述限定本人创建内容，不能将其当作完整公共词典。当前公开路径未列出通用词句／段落自动翻译操作。[官方规范](https://open.maimemo.com/api_bundle.yaml)
- 例句创建／更新及返回对象的`interpretation`表示调用方提供和保存的译文，不证明服务端自动生成翻译。官方演示称管理例句及翻译，与字段语义一致。[官方演示](https://www.maimemo.com/pages/openapi-demo/index.html)、[官方规范](https://open.maimemo.com/api_bundle.yaml)
- 本次核对公开API说明、开发指南、功能介绍及服务协议，未找到明确的API按次／订阅收费价目，也未找到全部接口免费的明确承诺。结论为“公开收费依据不足，待核实”，不是认定收费或免费；记忆卡产品免费说明和外部AI费用不能用来推导背单词API价格。[开发指南](https://memodocs.maimemo.com/docs/open/)、[功能介绍](https://memodocs.maimemo.com/docs/PNvOw2E1AivPtlkRlQgce1W1n2c/)、[服务协议](https://memodocs.maimemo.com/docs/open-terms)

### 词数上限与每日学习量不是同一维度

官方“重置学习数据”帮助确认：单词移出记忆规划后，账号上限总量不变，已用词量下降、剩余额度上升，同时该词记忆数据会被清除。它能证明额度与记忆规划之间有关联，但没有给本轮可统一适用的默认总词额和购买价格；本文不引用旧文章的免费词数或价格。[官方重置帮助](https://memodocs.maimemo.com/docs/KE8ZwhQ8UikDpKkeEggcKYgcnsd/)

官方每日学习量定义为当天复习与新学之和，通常先复习再新学。当天按设置安排的任务学完以后，再额外添加新词，会立即安排学习，不受每日量限制。故“只是加几词”可能改变当天安排与之后复习量，不能把加入记忆解释成纯收藏动作。[每日学习量](https://memodocs.maimemo.com/docs/PulqwOB1xi5jV0kb8Y1cPE7ZnKc)

## 学习和复习数据的语义限制

1. **平台状态受数据同步影响。** 官方帮助区分 App 自动同步和设备间手动上传／下载。API 取得的服务器数据不能默认等于尚未上传的设备即时状态。[学习数据同步](https://memodocs.maimemo.com/docs/TJDKwbRRfi1prCktSXPcDQjrnJf)
2. **记忆反馈是业务写入。** 官方解释“认识／模糊／忘记”会影响当天重复与以后复习；“熟知”使该词不再安排复习。它们不能被助手从一次对话表现推断后静默代填；本轮也未证实开放 API 向外提供全部反馈写入能力。[记忆反馈帮助](https://memodocs.maimemo.com/docs/Ok6YwF2X7iJZvvkCunjcmWwLnzb)
3. **预计复习日期不是固定课表。** 官方将复习间隔描述为按词难度、用户记忆数据动态生成，因此导出的待复习清单／时间应按当时状态理解，不能展示成不会变化的保证。[同上](https://memodocs.maimemo.com/docs/Ok6YwF2X7iJZvvkCunjcmWwLnzb)
4. **读数据不等于完成学习。** 官方功能介绍提出读取背诵进度和待复习词汇、生成学习清单；是否能把在本项目完成的每次复习写回官方历史与算法，要有相应请求契约才能确认，不能以“学习数据互通”宣传语代替。

前述属于语义判断；具体加词与提前复习动作见上文OpenAPI核查，不将“未列逐题复习反馈”扩大为完全没有学习类写接口。

### 官方网页版是独立入口

官方已有墨墨背单词网页版，但帮助明确目前为公测、逐步向账号开放，并且主要覆盖核心复习，体验与 App 有差异。它要求自动同步、最低 App 版本及公测资格。App 完成学习后退到后台才触发自动同步，同步后网页版才能取得最新进度。[墨墨背单词网页版帮助](https://memodocs.maimemo.com/docs/memo-web_study)

该页面列最低版本为 iOS 5.5.27、Android 5.5.25、HarmonyOS 5.5.03；这是检索时网页说明，并非本轮设备兼容性测试。“已有官方网页可复习”是复习入口证据，不是第三方 API 可代写逐题反馈、可内嵌或自动化操作网页的授权证据。

## 平台内容与用户自建内容的边界

功能介绍支持第三方 AI 工具把用户提供的阅读原文整理为云词本，但从墨墨读取平台释义／例句／助记另受版权内容条款约束，两者不能混为一种数据来源。[功能介绍](https://memodocs.maimemo.com/docs/PNvOw2E1AivPtlkRlQgce1W1n2c/)

官方服务协议第 7.6—7.10 条将内容类接口返回的释义、助记、例句等列为版权内容：须申请并获批该权限，限审核应用向授权用户在线展示，临时展示缓存最多 168 小时；规定不得持久汇编、自行二次分发、用于训练／微调或展示之外的数据挖掘分析等。内容与作者来源展示也有要求。[开放平台服务协议](https://memodocs.maimemo.com/docs/open-terms)

对本项目的直接含义是：**读到墨墨词汇内容不等于可以永久导入课程知识库或无条件发给模型处理。** 具体模型推理辅助、转发与缓存场景是否获准，应依审核范围和官方解释确认；本轮只记录合同原文及其对候选方案的影响，不作已获授权判断。用户原文、自创内容和接口取得的平台内容应保留来源区别。
