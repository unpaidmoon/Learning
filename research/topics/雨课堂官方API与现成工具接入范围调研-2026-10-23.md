# 雨课堂官方 API 与现成工具接入范围调研

检索日期：2026-10-23。仅研究与范围讨论，不代表正式需求、账号接入或实施授权。目标为雨课堂及其租户，不把学堂在线慕课、学堂云教学内容和每个雨课堂服务器自动视为同一数据源。

本日后续：用户已确认此前关键边界并接受完整建议方案，要求写入[雨课堂正式接入需求](../../docs/product/雨课堂接入需求收口-2026-10-23.md)，先不开发。首版只读课后学习、手动选取，接受标明来源的页图PDF，纳入回放／音视频／字幕、题目与可见反馈及变化提醒，明确排除实时自动跟随与公告／讨论弹幕／考勤统计等。下文“待确认”按研究形成时理解，产品范围以该收口为准；固定源码能力不自动全部采用，真实账号和读取副作用仍未验证。

## 证据范围与主要判断

本轮只读取官方页面、作者仓库 README、固定 SHA 源码、维护与 release 元数据；未安装依赖、登录、取得用户 Cookie、启动服务、请求真实媒体、调用学习状态／签到／作答或做模型测试。

现成工具已能提供若干局部实现：课件逐页图片合并 PDF、特定荷塘课堂回放下载、某些学校 LMS 视频和字幕、作业题图与本人作答归档。本轮未核得可共同依赖的标准个人开放API契约，也没有证明跨所有租户、课堂形态和权限稳定工作。功能名“PPT 下载”尤其不能直接解释为原始 PPTX。

下文分开记录官方声明、作者声明、源码分支与本项目未实测；HTTP URL 中出现 `api/open` 也不自动成为面向普通开发者的官方开放授权契约。

## 官方身份、租户与资源边界

| 议题 | 可核实的官方依据 | 仍不能推导的内容 |
| --- | --- | --- |
| 服务器与登录 | [官方网页登录](https://www.yuketang.cn/web) 列不同服务器入口；荷塘 `pro`、长江 `changjiang`、黄河 `huanghe` 和学校独立域名需分别理解 | 一个服务器登录后 Session、身份、classroom／lesson ID 在其他服务器自动通用 |
| 机构对接 | [官方套餐页](https://ww.yuketang.cn/en/set-meal) 面向学校、企业、机构列账户／学习数据对接 | 普通学生可自助取得相同接口、全校库或管理权限。未找到个人开放文档不等于断言不存在 |
| 课件导出 | [历史官方帮助](https://www.yuketang.cn/help?detail=52) 编辑于2017，说明课件打印及导出PDF，并称不提供原件下载 | 该旧帮助不是2026所有租户、角色与文件类型的绝对限制；也不证明第三方取回的PDF一定是原始上传文件 |
| 课件可见范围 | [官方更新日志](https://www.ykt.io/download) 当前有7.1.0（2026-06-17），提及课件可见性设置等 | 已进入班级就能读全部历史／未发布／隐藏页面，或能绕过教师可见范围 |
| 直播／回放 | [2021年官方直播流程](https://www.yuketang.cn/help?detail=162)区分教师授课和学生课后回看；当前功能仍按租户及角色核实 | 教师可管理／下载的内容不自动是学生可导出的媒体；能回看也不等于完整视频／字幕都可下载 |

本轮没有核实到公开可自助注册、权限描述完整的普通个人 API 契约。学校／机构对接与学生网页会话是不同路线，不能把作者调用网页内部接口说成平台正式承诺支持第三方。

历史帮助页面实时 HTML 可能只有动态壳，相关内容通过官方域名索引核对；当前版本信息采用官方更新页，不把旧教学手册当作2026运行验收。

## 课件与教师资料

### 长江：EdibleSalt

[固定README](https://github.com/EdibleSalt/yuketang-ppt-downloader/blob/0c414cc6ad67af038116ec1c5577d9c808712474/README.md) 明确长江租户、人工Cookie及课堂ID。源码固定 `BASE_URL=https://changjiang.yuketang.cn`：先读学习日志中的lesson，再取presentation IDs与slideList，逐张下载 `cover`，用Pillow保存PDF。[固定实现](https://github.com/EdibleSalt/yuketang-ppt-downloader/blob/0c414cc6ad67af038116ec1c5577d9c808712474/download_ppt.py)

这是**页图合成PDF**，没有PPTX对象、原始动画、可编辑文本／公式或原始演讲备注导出。图片分辨率和可见页范围取决于接口实际返回；存在PDF文件不能证明内容完整、所有图表清晰或有文字层。已有文件跳过也不等于基于来源版本的安全更新。

输入是已知课堂ID，不是现成全账号班级选择器；代码的读取请求以GET为主，但本轮没有核服务器是否记录访问，不能把“无显式签到POST”扩大为零业务副作用保证。

### 荷塘：proyuketang-afterclassCrawler

[固定README](https://github.com/fu-zc23/proyuketang-afterclassCrawler/blob/00523c91e48aabfba03cbd05d50c82fdec8ddbf8/README.md) 将范围限定为荷塘指定课堂；输入lesson_id，session无效时走微信扫码会话流程。源码访问固定 `pro.yuketang.cn`，课件用lesson-summary下presentation与slides的cover生成PDF。[固定实现](https://github.com/fu-zc23/proyuketang-afterclassCrawler/blob/00523c91e48aabfba03cbd05d50c82fdec8ddbf8/afterclass_crawler.py)

它同样不是PPT原件下载，也没有证明能下载教师发布的所有PDF／Word／压缩包／云盘资料。扫码得到的是该网站会话，不是雨课堂官方个人第三方OAuth；不能把固定域名替换后就视为长江、黄河或学校租户通过。

## 作业、课堂题、本人答案与批阅

[wengzige固定README](https://github.com/wengzige/yuketang-homework-exporter/blob/c2d8f57f77fa303fccefed04405dde17997cae8b/README.md) 声明复用本机Edge／Chrome已登录profile，从课程作业生成Word。固定脚本读取LMS chapter，筛选leaf_type=6，取leaf_info与exercise list，在浏览器使用原字体渲染题目截图，整理用户字段。[固定实现](https://github.com/wengzige/yuketang-homework-exporter/blob/c2d8f57f77fa303fccefed04405dde17997cae8b/export_yuketang_homework.py)

| 对象 | 可核实覆盖 | 不能说成什么 |
| --- | --- | --- |
| 题干与选项 | 浏览器渲染题卡截图，避免字体混淆；输出DOCX | 不等同可搜索纯文本题库、原始试卷文件或PPT源件 |
| 本人作答 | 读取`my_answer/my_answers`，按题型格式化 | 不等同标准答案，也不证明可读取他人的作答 |
| 判定／分数 | `is_right/my_score`等平台可见字段 | 不等同所有题已完成教师批阅、所有解析已开放 |
| “官方答案”栏 | 函数`official_answer_from_problem`在平台判正确且满分时，把本人答案当作可确认答案，并附解释 | 这是**由本人满分正确作答推得**，不是独立标准答案字段；集成时必须保留该来源身份，不应照输出标题写成平台返回的标准答案 |
| 范围 | 给定课程下的作业leaf与筛选项 | 不证明所有课堂随堂题、独立考试系统、尚未开始试卷和每个租户都支持 |

该脚本的接口读取用浏览器凭据；它不是机构开放API。读取页面可能有平台行为记录，本轮没有验证零副作用或全部题型覆盖。普通截图归档和完整结构化课程知识库仍是不同交付物。

## 混合自动化不能直接当只读连接器

thuhollow2项目有当前更新与扫码会话，也有班级列表、课件和试卷获取，但同时实现自动加班级、签到、课堂答题、考试token及大模型辅助。`checkin_lesson`会POST `/api/v3/lesson/checkin`，随后保存授权／lessonToken等信息；不是只读读取。[固定README](https://github.com/thuhollow2/yuketang/blob/b5da7837dc187c9b7a960623e4d196727637aa3d/README.md)、[固定yuketang.py](https://github.com/thuhollow2/yuketang/blob/b5da7837dc187c9b7a960623e4d196727637aa3d/yuketang.py)

因此，“为了取得课堂授权先签到”不能被藏在导入流程中。配置里有关闭按钮、作者列PPT下载、提供APK，都不能证明整个程序启动后无写操作。若以后研究裁剪，应逐入口确认调用链、身份前提、网络请求与业务效果，而不是依赖提示词禁止作答。本轮没有运行或调用这些动作。

## 覆盖矩阵与未确认产品边界

| 可能的学习动作 | 本轮证据结论／仍需讨论 |
| --- | --- |
| 登录并列全部班级／课程 | 会话与部分列表实现存在；服务器、学校身份与数据范围要分别确认，不默认跨租户聚合 |
| 课后课件导入 | 两条较窄脚本能按指定课堂取页图合PDF；原始PPT／教师其他附件另核 |
| 直播／回放导入 | 指定荷塘回放和某学校LMS视频有实现；直播录制、完整音视频／字幕覆盖尚未确认 |
| 已提交作业复习 | 有题图＋本人作答／平台分数归档工具；标准答案推断、批阅时机与可见性需保留 |
| 随堂题／正式试卷 | 读取常与加入课堂／签到／考试会话有关，不能自动沿用作业工具能力 |
| 业务只读与正式提交 | 应由用户确认；不能把其他平台已讨论边界直接当雨课堂已决定，也不默认启用签到或答题 |
| 模型可读范围 | 需要确认选中课堂、某次课、资料、页或题目的范围；不因连接浏览器就发送全课或屏幕 |

后续grilling可围绕租户／连接路径、课件派生件可接受程度、回放与字幕、作业复习和正式提交边界逐项收口，本文不预先替用户选择。

未覆盖：2026真实账号与租户兼容、Cookie／扫码有效期、学校身份绑定、页图清晰度与缺页、原件下载权限、回放时效与加密、字幕实际格式、题目与评分完整性、读取副作用、取消恢复与来源版本对账。所有源码／README只是研究证据，不是本项目验收。本次形成本报告并补充研究导航，未变更正式需求或应用代码。
