# 中国大学生学习场景与平台调研

调研日期：2026-10-23。对象包括中国高校本科生、硕士生和博士生；覆盖课程学习、语言、记忆、练习、专注、资料、协作、科研、实践与成果表达。依据用户补充要求，单独列出可核实的百分比、样本与缺口。本文是研究材料，不代表需求确认或开发授权。

## 证据口径

- 平台能力依据平台官方页面，高校实际组织方式依据教务处、学院或信息技术部门的通知及手册。二者分开理解：有某项功能，不等于学生普遍使用；学校发出通知，也不能代表全国高校。
- 所列是有证据的代表平台与学习流程，不是全国使用率排名。百分比按各来源的调查样本报告；本次未取得同时覆盖全国、学历、专业与年级的代表性平台调查，不将地方样本、媒体问卷或官方产品规模当作全国渗透率或市场份额。
- 官方网页在检索当日可访问，不等于已登录验证全部功能。本文未登录学生账号、下载网课视频或测试课程成绩与学分同步。
- 平台注册用户、全球学习者、课程选课人次、视频播放量、粉丝量均不能直接转换成中国在校大学生人数。公开课程证书也不能直接等同于本校学分。
- 下列来源检索日期统一为 **2026-10-23**；没有明确发布日期的网页注明“未标明”，不把检索日期当发布日期。

## 一、先看能核实的统计数据

下列“全国高校调查”表示征集范围涉及全国，不等于按全国学生总体做了概率抽样。媒体报道没有公开原始问卷、逐题有效人数和抽样权重的地方均保留缺口。调查年度、论文发表年度和网页抓取时间分开；不同调查不能拼成同一总体的排名或趋势。

### 1. 网络学习内容、场景与困难：2023 年，3486 份问卷

中国青年报·中青校媒于 2023-05-05 发布调查，回收来自 167 所高校的 3486 份有效问卷。原文未公布本科／硕士／博士构成、逐题样本量和全国加权方法。以下为原文的受访者比例；多种内容和困难可以同时存在，不能相加成互斥分布。

| 指标 | 原文比例 | 可支持的场景判断 |
| --- | ---: | --- |
| 曾通过网络辅助学习知识或技能 | 97.4% | 网络学习在该样本中覆盖广，不能据此推算全国人数 |
| 观看专家发布的课程 | 70.6% | 系统网课与知识点讲解 |
| 观看学习博主分享的学习经验 | 63.9% | 学习方法、备考路径与经验获取 |
| 检索绘画、摄影等特长技能 | 38.4% | 兴趣、创作与实践技能 |
| 检索非本专业知识 | 37.3% | 跨学科学习 |
| 检索生活实用技能 | 37.1% | 学习边界还包括生活能力 |
| 跟随学习博主线上自习 | 33.7% | 陪伴、共同学习与外部监督 |
| 观看视频类学习内容 | 84.4% | 视频值得单独考虑，但不等于某视频网站的使用率 |
| 观看图文类学习内容 | 63.0% | 资料阅读、图解和笔记同样重要 |
| 认为网络学习容易分散注意力 | 64.9% | 专注是实际困难；不能换算成番茄钟使用率 |
| 认为学习内容质量不高 | 54.5% | 需要辨别来源与内容质量 |
| 认为寻找合适学习内容费时间 | 50.6% | 资源筛选与组织成本 |

来源：[中国青年报原始报道](https://zqb.cyol.com/html/2023-05/05/nw.D110000zgqnb_20230505_1-07.htm)。这里不采用“每天用社交网络学习 50.8%”作主结论，因原文“其中”对分母存在歧义。以上是 2023 年的调查，不能称作 2026 年现状普查。

### 2. 具体课程平台：2024 年发表，昆明高校 354 人

姜雪晗等的原始论文《探究使用自主学习软件及其依赖对学习效率的影响——以昆明市大学生为例》于 2024-05-31 发表，使用自编问卷和问卷星回收 354 份有效问卷。对象来自云南大学、昆明理工大学、云南师范大学等昆明高校：本科 208 人、专科 109 人、研究生 37 人。原文没有给出准确调查起止日、完整平台题题干、逐题有效分母或明确的多选标识。

| 平台 | 论文报告的该样本比例 |
| --- | ---: |
| 中国大学MOOC | 41.2% |
| B站 | 41.0% |
| 雨课堂 | 35.9% |
| 学习通 | 33.0% |
| 学堂在线 | 22.6% |

这些比例可以重叠，不能相加计算总覆盖率。中国大学MOOC与B站相差 0.2 个百分点，原文未给相应差异检验，不能据此断言总体排名。论文没有按学历分别报告平台比例，不能把混合样本数字标成“研究生使用率”。

同一论文的表 1 明确给出使用方式的频数及分母：基本不用 33/354（9.3%）、期末突击 77/354（21.8%）、遇到没掌握的知识点时使用 136/354（38.4%）、配合线下课堂有计划地使用 108/354（30.5%）。这支持把临时解惑、期末复习和持续跟课分成不同场景。

来源：[原始论文 PDF，第 1148—1150 页](https://pdf.hanspub.org/ae2024145_1751166263.pdf)，DOI：10.12677/ae.2024.145819。证据等级为地方探索性调查；不采用其相关分析推断软件使用导致学习效率变化，也不由该样本估算全国渗透率。

### 3. 较近期的社交学习：2025 年，1772 份问卷

中国青年报·中青校媒于 2025-12-22 发布、面向全国高校学生征集的 1772 份有效问卷中，62.08% 将学习或技能提升列为使用社交媒体的原因，40.69% 认为社交媒体能提升学习效率。这能支持学习经验、资源发现、同伴交流进入场景图。

原文“抖音、B站等视频平台 72.18%”是合并选项，且涉及一般社交媒体使用，**不能写成 B站学习使用率 72.18%**。问卷未披露逐题有效人数、学历构成和全国加权方法；各类用途有重叠。来源：[中国青年报原始报道](https://zqb.cyol.com/pc/content/202512/22/content_420243.html)。

### 4. 付费学习需求：2025 年，4480 份问卷

中国青年报·中青校媒于 2025-09-02 发布知识付费调查，4480 份有效问卷。原文报告受访者涉及兴趣课程 46.54%、专业技能证书备考 39.75%、考研／考公／留学辅导或资料 36.96%、付费阅读／音频 34.08%、职业技能培训 29.35%。动机中，提升学业成绩、辅助专业学习为 60.04%。

这支持考试、兴趣、职业能力与阅读等并存，不能把上述比例理解为全部大学生的付费率。原报道未提供完整题干、逐题人数及是否仅由付费者回答这些题；项目可重叠。来源：[中国青年报原始报道](https://m.cyol.com/gb/articles/2025-09/02/content_JQEmYAsZBO.html)。

### 5. 背词软件：2022 年小样本，只作历史线索

山东大学材料科学与工程学院于 2022-04-12 公布课程小组调查，持续三周，86 份有效问卷。报道的“英语类 app 中”比例为：墨墨背单词 26.09%、百词斩 20.29%、扇贝单词 17.39%。

**不能称为当前大学生背词软件市场份额。** 原报道未公开该题具体回答人数、是否多选和统计分母；百分比不能直接按总样本 86 人还原。其工科小样本、旧年份和方法披露不足，使它只能用来确认这些品牌曾进入学生学习工具清单，不能据此排名或决定产品优先级。

来源：[山东大学学院原始发布](https://www.cmse.sdu.edu.cn/info/1438/26029.htm)。本轮未找到可核验的 2024—2026 年全国本科／硕士／博士分层背词品牌使用率。

### 6. 研究生专门证据：调查发生于 2024 年，2026 年发表

《中医教育》2026 年第 45 卷第 3 期《中医类专业研究生生成式人工智能应用现状调查分析》，调查时间为 **2024-07-27 至 2024-08-07**，采用便利抽样，覆盖中国中医科学院和北京中医药大学中医类专业研究生，475 份有效问卷。研一占 71.16%，博士及以上占 5.26%，不能视作各学科、各年级均衡的研究生样本。

原文报告 **90.30%** 受访者使用过人工智能工具，常见功能是写作润色和语言翻译，常见情境是科研和课程学习。只在此特定样本下使用该比例，不能写成“全国研究生 AI 使用率”。不采用摘要中“73.20% 形成稳定使用习惯”作独立主指标，因为其“其中”的分母和“稳定”的定义需要进一步核对原表。

来源：[期刊原始论文](https://cjournal.hep.com.cn/1003-305X/CN/1251928659331273573)，DOI：10.3969/j.issn.1003-305X.2026.03.312。网页提取器未完整展示正文，本轮通过期刊站点 HTML 直接读取并核对摘要、研究对象和数据收集段；没有把发表年当调查年。

另有《中国高教研究》2025 年研究分析 14817 份研究生问卷，其原刊摘要支持博士、硕士的学术写作辅助需求存在差异，但本轮未取得可完整核对的比例表，因此不填百分比。来源：[原刊条目](https://zggjyj.cahe.edu.cn/CN/10.16298/j.cnki.1004-3667.2025.01.10)。

### 7. 番茄钟与其他软件的数据缺口

本轮未找到口径清楚、近期、可以代表全国大学生或分别代表硕士／博士的番茄ToDo、Forest、潮汐、滴答清单使用率。也未取得 Zotero／EndNote、笔记软件和各类 AI 品牌在这些群体中的可比全国份额。**未找到不等于没人使用；代表工具存在也不等于大多数学生使用。**

不使用应用商店评分人数、平台累计下载量、年轻用户占比、在线自习参与率来替代番茄钟使用率。问卷星／问卷网仅有题目、没有回收数据和方法的问卷不作为统计结果；竞品分析中没有原始来源的饼图也不采用。路径含 2021 的艾瑞《中国大学生在线学习白皮书》实际调查于 2017 年，本轮未拿它补当前份额。

## 二、完整学习场景地图：本科与研究生共用部分

以下是对一手来源和实际工作流程的归纳，不是按使用人数排列。工具列是代表例子，每个学生可以只使用其中一部分；没有百分比的条目不暗含已证明普及率。

| 场景 | 学生实际要完成的事 | 代表软件或入口 | 主要材料／成果 |
| --- | --- | --- | --- |
| 找课、选课、接收教学任务 | 查课程安排，进入教学班，接收截止日期 | 校内教务、学习通、雨课堂、学校 LMS | 课程、通知、任务清单 |

| 作业与习题 | 完成课程练习，订正、重做与归纳错因 | 纸笔、课程作业系统、Word、AI 助手 | 原题、作答、反馈、错题 |
| 考前复习与模拟 | 期中期末、四六级、考研、考公、考证 | 课程资料、真题、粉笔等目标考试平台 | 考纲、提纲、模拟卷与错题 |
| 编程练习 | 学语言、算法、调试、提交与看反馈 | 学校 OJ、力扣、牛客、GitHub | 源码、运行结果、题解 |
| 笔记整理与知识组织 | 把分散笔记、解释和来源整理成可回看的结构 | OneNote、Obsidian、幕布 | 大纲、知识链接、复习笔记 |
| 规划与提醒 | 安排今天／本周学习，管理多门课截止时间 | 滴答清单、系统日历、教务课表、纸质计划 | 待办、日程与检查点 |
| 专注与防分心 | 开始自习、控制手机切换、安排休息 | 番茄ToDo、Forest、潮汐、滴答清单 | 专注时段与任务关联 |
| 同伴学习 | 互相答疑、共同自习、交流方法 | QQ／微信群、课程讨论区、线上自习 | 讨论、约定与共享资料 |
| 小组作业与课程项目 | 分工、共同编辑、收集数据、合并版本 | 飞书文档、GitHub、Word／表格 | 项目文件、分工与修订 |
| 汇报、演讲与答辩 | 组织观点、做 PPT、排练与回答问题 | PowerPoint、会议软件、协作文档 | 幻灯片、讲稿、反馈 |
| 实验、实训与竞赛 | 按方案操作，建模，记录与分析结果 | 实验记录本、表格、MATLAB／Simulink、学科工具 | 实验记录、模型、作品与报告 |
| 兴趣与跨学科拓展 | 学摄影、设计、第二外语等 | B站、开放课程、图书馆、专业社区 | 练习、作品与新知识 |
| 升学、求职与技能准备 | 查官方要求、练笔面试、整理经历与作品 | 学校／院所官网、牛客、经验社区 | 申请材料、练习与作品集 |
| 资料采集与跨设备整理 | 扫描纸张、收课件、管理多个版本、电脑与手机接续 | 扫描全能王、校园云盘、文件夹、笔记／文献软件同步 | 原件、扫描件、来源与备份 |
| 学习回顾与调整 | 判断哪里还不会、回顾作答和计划执行 | 错题／卡片记录、待办与专注统计、学习日志 | 学习证据与后续行动 |

“专注时长”“看完视频”“收藏资料”都是过程记录，不能直接等同学会。纸笔、打印教材、线下讨论、仪器操作仍属于完整学习流程，不能因研究软件而遗漏。

上表的工具功能依据见下一节官方来源；课堂与课程流程见后文平台对照。AI 品牌进入学生学习流程的实际例子见[中国青年报 2025 年 3129 份问卷调查及访谈](https://m.cyol.com/gb/articles/2025-09/22/content_aj673OFBVx.html)。该调查是媒体联合平台征集样本，不作为全国 AI 品牌排名。

## 四、硕士与博士新增的科研学习链条

研究生继续使用上面的课程、语言、计划和专注工具，同时增加围绕课题的持续工作。下表是任务分析，不为不同学历编造发生率；本科毕业设计和大创也可能进入这些场景。

### 分层理解，而不是把研究生视作一个群体

| 人群／阶段 | 分析时应重点核实的任务差别，不是统计结论 |
| --- | --- |
| 本科低年级 | 适应课程、公共基础、英语、课堂笔记与学习习惯 |
| 本科高年级 | 专业项目、竞赛、实习、升学准备与毕业设计 |
| 硕士初期 | 课程、文献入门、研究方法与工具学习 |
| 硕士课题阶段 | 持续读文献、实验／调研、数据、组会与论文 |
| 专业学位研究生 | 行业实践、临床／工程／教学训练与课题并行；不能默认均以实验室论文为唯一中心 |
| 博士阶段 | 长周期问题定义、领域跟踪、多轮研究、投稿修改和成果组织；实际差异需再按学科验证 |

实验学科侧重实验条件与原始数据；计算学科侧重代码、环境和复现；人文侧重史料、文本与论证；社会科学侧重访谈／问卷与方法；医学还可能有临床轮转。此为访谈分层框架，不意味着每个学生都符合单一类型。

## 五、几个跨软件学习流程示例

这些是依据前述能力组合的情境示例，未声称来自追踪观察，也不推算使用率。

1. **本科课程补课**：课堂没听懂 → 课件与教材定位问题 → B站或慕课找讲解 → 笔记／AI解释 → 自己做题 → 回课程平台提交作业。
2. **英语备考**：目标词书背词 → 阅读／听力遇到生词 → 查词并保留原句 → 做真题与写作 → 错误订正 → 后续复习。
3. **期末自习**：从多门课列任务 → 安排自习时段 → 打开资料并计时 → 完成练习 → 按作答问题调整下一轮；完成时长不等于掌握。
4. **研究生论文精读**：数据库找到论文 → 文献管理软件保存 → 原文批注、术语解释与方法比较 → 形成有引用的组会材料 → 接收导师反馈 → 调整课题方案。
5. **研究生科研产出**：方案 → 实验／调研 → 原始记录 → 数据／代码分析 → 图表 → 论文草稿 → 导师修订／审稿意见 → 版本与引用持续维护。

## 六、对本项目的研究启示，尚未确认为新增需求

- 课程与研究课题都有材料、问题、笔记、练习和成果，但研究课题还需要文献身份、方法、数据、实验与稿件版本。可以先讨论组织对象能否兼容课题，不据此自动改造课程模型。
- 视频、PDF、作答、笔记和回到原文的衔接值得优先验证；不能只看平台数量。现有证据支持这些任务存在，但没有证明哪个集成入口最受欢迎。
- 背词、间隔复习、任务计划与番茄钟分别服务不同动作。代表软件可以用于比较成熟交互；是否自建、仅提供导出或保留外部工具，需要结合用户选择，不能用数据缺口推断应全部自研。
- 课堂／考试平台承担本校身份、成绩和提交。本项目的学习辅助不自动取得这些平台的账号、素材或学分流程；本轮没有验证任何平台 API、导入或视频接入。
- “容易分心”“找材料耗时”是已报告的样本困难；是否能由本项目解决，还需要实际学习任务验证。统计不能自动变成功能优先级或实施授权。

与项目既定边界核对时，参照[13 场景需求收口](../../docs/product/13场景学习工作台需求收口-2026-10-23.md)及[PDF、字幕与知识库需求](../../docs/product/PDF阅读与字幕及课程知识库需求收口-2026-10-22.md)的后续覆盖说明，不以更早记忆中的暂缓结论覆盖当前文档。

### 容易混淆的名称与动作

1. **“慕课”是一种课程组织方式，不仅指中国大学MOOC这一品牌。** 学堂在线、学银在线、智慧树等也承载慕课。陕西师大在同一选课通知中并列多个来源平台，直接说明一所学校可能同时引进多平台课程。[陕西师大教务处，2026](https://jwc.snnu.edu.cn/info/1623/31594.htm)
2. **“自主安排学习时间”不等于“没有截止日期”。** 淮安大学要求学生自主安排网课学习，同时完成视频、测试、作业、讨论与考试并注意提交期限。[淮安大学教务处，2026](https://jwch.hau.edu.cn/info/1124/7340.htm)
3. **“在平台学了课”不等于“本校确认修了课”。** 该校通知将教务选课、学校认证、加入慕课堂等列为成绩与学分认定条件。具体条件是单校规则，不能推广为所有高校统一政策。[淮安大学教务处，2026](https://jwch.hau.edu.cn/info/1124/7340.htm)
4. **课程学习之外仍可能有班级沟通渠道。** 中国矿业大学 2026 年通知同时列教务选课、指定学习平台与课程 QQ 群，体现通知／答疑和课程学习可能分处不同工具。这是已证实的校内流程，不是全国使用率结论。[中国矿业大学教务部，2026](https://jwb.cumt.edu.cn/info/1102/8438.htm)
5. **“校内平台”不一定是学校从零开发的软件。** Moodle、超星等底座可以采用学校品牌；反过来，同一学校也可并存多个平台。华师大通知正是整合与替换案例，不能假定全国存在一个统一入口。[华师大本科生院等，2025](https://bksy.ecnu.edu.cn/b6/22/c40631a701986/page.htm)

## 后续核实重点

这批平台证据能建立场景清单与访谈提纲，不能单独决定产品优先级。若需要判断“最常用”“最痛”或付费意愿，应补充按本科／硕士／博士、专业、年级、学校类型分层的学生访谈与近期行为记录，并区分必须完成的课程任务和主动学习。研究建议不自动成为本项目需求或实施决定。
