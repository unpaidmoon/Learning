# AI 辅助学习项目

个人学习工具，以考研数学一为试点。首个 MVP 聚焦 Windows 上的视频主动截图、编辑、文字提问与完整讲解，减少截图中转和软件切换，并统一资料与知识库。

## 当前状态

**处于 MVP 开发准备阶段，尚无正式应用代码、安装包或可运行的开发入口。**

已完成需求澄清、技术选型、全面立项调研与有限组件验证：

- Harness `0.2.1rc2` 隔离启动及空会话接口有局部通过记录，学习 preset、真实图文流和生成中停止仍需实现与验证。
- 60 秒本地 ASR 推理已完成，但 DLL 环境交付、时间越界和前后台并行尚未验收。
- 默认 Harness 制品存在 workspace-controller、Office provider 的缺依赖记录，不能以 Host ready 视为全部插件可用。
- 详细结果、限制和脱敏证据见立项报告。研究 probe 只用于诊断，不是产品代码。

## 核心路线

```text
Windows 定制浏览器界面
    → 项目业务后台与自有数据
    → Harness 执行宿主及学习插件
    → DeepSeek 官方 API

本地转写/资料处理 → 独立 Python worker → 应用任务与产物
```

用户截图与文字优先；必要时补字幕，再不足时补知识库。AI 不自动补取视频画面。原始资料原地引用，完整聊天与已提交附件由项目管理。

安卓后续提供独立基础学习与直接问答，具备同步条件后合并数据；不要求运行完整 Harness。Tailscale 是连接层候选，业务同步由项目负责。

## 运行产物与版本控制

- 原视频、课件、数据库、模型、缓存、私有配置和内部执行 home 不作为源码入库。
- `research/probes` 保留本地诊断产物；Git 仅白名单保留指定脚本和脱敏 JSON，不包含下载的 runtime、wheel 或私有 home。
- 开发和构建目录、依赖缓存由 `.gitignore` 排除，锁文件正常入库。
- 规范及文档使用 UTF-8；编辑约定见 `.editorconfig` 和 `.gitattributes`。
