# Harness 原生界面学习桌面试用

2026-10-25启动入口更新：双击根目录[启动学习.cmd](../启动学习.cmd)或[启动Harness桌面.cmd](../启动Harness桌面.cmd)，二者统一使用隐藏的GUI启动器。启动器核对后台身份和资料位置，恢复已有窗口或为仍正常运行的后台重开窗口；端口被其他程序占用时改用空闲端口，不结束占用进程。重复启动由同资料位置的启动锁保护。完全退出使用托盘“退出 AI 辅助学习”，不需要任务管理器。以下早期入口与实现描述按日期理解；最新功能范围见[本轮交付记录](../research/reports/workbench/Windows定向改造与精简验收-2026-10-25.md)。

此入口以固定 DeepSeek Harness 制品中的原版 Web 客户端为基础，通过 Electron 显示。主题、输入框、消息渲染、模型选择和菜单复用原生实现；**整体结构沿用本项目：左侧课程目录、中间资料区、右侧 AI 对话**。中间有常驻“文件”标签和可关闭的视频标签，同一时刻展示一个资料。窗口外壳按上游代码适配，本项目独立维护，不是 DeepSeek 官方桌面发行版。

界面按精简原则整理：常驻课程、资料和当前对话，空聊输入框在底部；课程与对话工具在悬停或键盘聚焦时出现，文件操作随选中状态变化。左下“设置”统一配置入口；UI 主文字使用原生字体与 14px，代码／数学字体保留。短动效不妨碍拖动，支持系统减少动态效果。真实界面截图、REA 依据与分层结果见 [界面与交互记录](../research/reports/harness-desktop/桌面精简界面与交互验证-2026-10-22.md)。

桌面已接入文件管理、图片/TXT/Markdown阅读、视频/全屏/确认截图、整份文档附件、回答引用与自动草稿。本次13场景实施还接入固定PDF.js内嵌阅读：目录、搜索、翻页、缩放/旋转，原版本选区加入AI、局部翻译自动保存/索引和原文高亮。右侧继续沿用原生输入/消息/模型选择。扫描OCR、字幕及其余场景仍在实施；阅读组合21项合成浏览器证据见[记录](../research/reports/workbench/PDF阅读与选区闭环验证-2026-10-23.md)，不代表全场景或用户体验通过。授权及唯一工作包状态以[MVP计划](../docs/plans/MVP开发计划.md)为准。

## 接入方式

- 固定来源及实际客户端发行身份分别见 [desktop.lock.json](../harness/desktop.lock.json)。SEA 实际发布的 UI build 为 `332895e`，参考源码为 `687f282e…`，不将两者视为同一源码构建。
- 官方 UI 由项目后台同源代理。浏览器只持有应用会话，Harness 启动 token、签名 cookie 和模型凭据均留在后台。
- 原生发送、停止和模型选择经过项目业务适配；课程、聊天、截图、生成、实际出站 attempt 和 raw usage 仍归项目存储。模型可见的截图只包含用户确认的矩形。
- SEA 缺失的 Workspace 浏览器 provider 由固定官方源码补齐，输入、编译器及产物摘要见 [构建来源](native-workspace.sources.json)。Workspace 数据由项目课程和会话映射投影，未另外维护一套课程数据库。
- 项目原文件管理、资料阅读、草稿／截图和播放器编译为共享 Harness React 与原生控件的学习模块；运行产物位于忽略的 `.runtime/desktop/client/`，启动准备时按锁定工具构建并核验源文件摘要。
- 课程加入后后台生成并缓存低分辨率预览图，悬停使用预载邻近帧；播放、截图与问答优先。预览图只用于本地界面，不能自动进入模型。空对话重复点击“新对话”保留文字与附件；补充条件、纠错直接发普通消息，旧稿相应内容转为正文保留。
- “本对话附件”可下载已提交原件、跳回截图的原视频版本和时刻；左栏可切浅色、深色或跟随系统。主题只开放指定偏好写入，其他 Host 设置继续受限。
- 本闭环未启用终端、任意文件读取、插件安装、自动联网或子代理工具。未接入操作由后台拒绝，不能通过改变客户端请求恢复能力。

## 运行与数据

2026-10-24新增可搬迁运行候选，固定依据见[portable.lock.json](../harness/portable.lock.json)，证据及未完成门槛见[Windows运行记录](../research/reports/workbench/Windows可搬迁运行闭包验证-2026-10-24.md)。候选解压后双击“启动学习.exe”，包内含Python／Node／Electron／Harness和本地学习资源，不要求终端或开发工具。默认业务数据保存在`%LOCALAPPDATA%\LearningWorkbench`，与下方源码桌面试用目录不同。仅完整性／本机搬迁／自然退出／冷恢复技术层已验证；统一场景、干净Windows和数据管理体验尚未全部验收。

构建端使用项目Python运行`scripts/desktop/build_portable.py --output <尚不存在的目录> --release-id <固定标识>`，先核所有资源及bundle，再构建无第三方crate的固定Rust入口。对已核验目录运行`scripts/desktop/archive_portable.py <目录> <新ZIP路径>`只封装清单文件，逐个从ZIP解压核hash；不将运行产生的缓存带入新包。两个命令均已在本项目实际成功执行；构建工具由开发端持有。

默认桌面后台端口为 `8766`，数据位于 `.runtime/desktop/app/data`，与旧浏览器试用数据分开。首次使用在左栏创建课程，选择真实课程文件夹；目录窗口绑定当前桌面窗口并前置。中间“文件”页负责整理和打开资料，外部拖入／粘贴只复制，删除进入回收站。截图确认只加入草稿，仍需用户点击原生发送按钮。

视频全屏时可用 `Ctrl+Shift+A` 或右边缘唤起 AI；收起 AI 后继续播放。`Ctrl+Shift+S` 可框选本软件可见范围。未发送截图可重新裁剪，替换草稿中的图片且保留旧确认资产与来源关系。正文、附件和引用自动保存；出现草稿冲突时保留两份内容供选择，提交结果未知时先核对原请求，不自动重发。

关闭窗口会隐藏到托盘，视频页面与后台保留；托盘退出通过业务后台核对活动生成再退出。显式停止回答只取消对应会话，不关闭 Harness 宿主。账号与 API Key 沿既有凭据路线配置，不会因账号不可用自动切换。

双击根目录 [启动Harness桌面.cmd](../启动Harness桌面.cmd)。开发及验证入口见 [scripts/desktop](../scripts/desktop/)，固定上游许可和改编文件范围见 [SOURCES.md](SOURCES.md)。最新分层证据见 [验证入口](../docs/validation/README.md)；首轮 21 项合成浏览器、真实模型 3 次／15 项及独立 Electron 验证保留在 [原验收记录](../research/reports/harness-desktop/Harness桌面学习闭环验收-2026-10-22.md)，不冒充本轮迁移复测。

执行仍可携带允许的已提交题图和完整文档历史；局部翻译使用隔离任务，只提交选中文字。实际出站按原始请求记录，正文展示不重复画出保护上下文。既有浏览器和数据保留，桌面不自动合并两套数据。本次授权内的字幕/课程知识库继续开发，Office、Android/同步不由本轮顺带扩展。官方账号在此次新增阅读链未真实登录复测，用户正常学习与主观视觉评价仍待参与。
