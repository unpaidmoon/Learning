# 学堂在线接入需求收口

2026-10-24补充：共用入口、默认关闭／按需加载、连接与停用、身份／任务／确认规则按[共用准备需求](平台接入共用准备需求收口-2026-10-24.md)执行；独立责任和验收见[并行交接](../plans/八平台模块化并行开发交接方案-2026-10-24.md#47-学堂在线xuetangx)。只读、手动范围及排除项不变，不与雨课堂合并模块或授权；本轮仅文档、不开发。

日期：2026-10-23（Asia/Shanghai）。依据：本聊天先核查官方API及现成工具，按用户原则一次给出完整建议方案；用户最终确认“全部接受，按这个范围收口，写入学堂在线接入需求文档，先不开发”。

本文是本轮学堂在线接入范围的主要需求来源，与[需求总结](AI辅助学习项目需求总结.md)、[13场景需求](13场景学习工作台需求收口-2026-10-23.md)共同理解。实现与验收状态只在[MVP开发计划](../plans/MVP开发计划.md)维护。官方／网页接口、历史工具及证据缺口见[专题调研](../../research/topics/学堂在线官方API与现成工具接入范围调研-2026-10-23.md)；需求确认不代表真实账号、接口或兼容性已经验证通过。

## 1. 定位、分期与本轮授权

- 以Harness为统一学习入口，连接用户选定且有权访问的学堂在线课程，复用本项目阅读、播放、提问、本地练习、成果保存和复习能力。
- 本项目完整保存学习成果，平台正式计分及提交状态与本地学习记录分开。
- 当前13场景继续按原范围和已有授权交付，本接入不增加为其交付门槛，也不将已有场景移到后续平台阶段。
- 2026-10-24更新：后续共用接口收敛、平台独立并行开发、单独验收，不再要求等待B站完成；本次不启动实施。
- **本轮只写入需求与同步文档，先不开发。** 不修改业务代码、数据库、依赖、运行配置或工具权限，不安装工具／SDK、不启动服务、不登录账号、不读取私人课程、不下载真实媒体或调用模型测试。本条不撤销其他聊天已有实施授权。

## 2. 平台与课程范围

- 以公共学堂在线为主要入口，纳入账号可访问的公开课、已购课程及历史期次，按真实权限、资源开放状态和有效期分别核验。
- 学校学堂云／SPOC纳入独立连接范围，分别核对学校身份和权限，不把公共MOOC账号或已购资格当成学校学分课访问权限。
- 与[雨课堂接入](雨课堂接入需求收口-2026-10-23.md)已有适配可以复用，但不默认共用会话或合并课程；相同来源的识别和映射以实际身份为依据，不仅凭同名、相似URL或同一供应商判断。
- 保留平台入口、学校／租户、课程、班级和期次身份。当前官网与next入口使用相同前端制品，不能据此认定所有会话、权限和资源版本互通。
- 同名课程、不同班级及历史期次不自动合并；旧期资源失效不静默换成新期。试看、未发布、已关闭和权限不足分别标识，试看不算完整内容。
- 接入目标不等于承诺所有学校和课程已兼容，后续按实际入口和课程类别分别验证。

## 3. 平台端只读与正式学习状态

- 本项目只读取和导入已确认范围，保存自己的观看进度、练习和成果；正式提交、考试及需要平台计分的学习仍在原平台完成。
- 不自动选课、退课、提交答案、上报学习进度、标记完成或重置学习记录；获取内容时不能隐含执行这些动作。
- **只读按具体业务效果落实，不能仅禁止POST。** 调研已核到官网公开代码中“我已看完”与重置单元采用GET的反例；相应操作不因使用GET就被允许进入读取白名单。
- 登录、页面访问、资源读取与播放是否产生业务记录，须后续按实际调用链核查，不能用方法名、HTTP动词或没有显式心跳代码证明零副作用。
- 本地重新作答、AI参考评价、错题和复习不覆盖平台原作答或教师批阅，不冒充平台已完成任务。

## 4. 导入入口、选择与资源管理

- 支持浏览“我的课程”，同时支持粘贴课程或学习页链接；明确课程、班级或期次后由用户选择，不自动选退课或整课导入。
- **所有导入可手动分别选择范围**：章节、视频、课件、附件、章节富文本及具体题目，保留实际所选范围和获取结果。
- 导入到用户选择的本项目课程，在中间资源管理器保留课程与章节结构、资源顺序和平台来源。
- 支持来源图标、预览、改名和移动，操作只影响本项目，不修改远端资源；来源身份、阅读／播放进度、问答和成果关联继续保留。
- 分页、目录和资源子项覆盖可核对，不把第一页、部分可见课程或单个视频当成完整课程列表／整课导入。
- 导入与向模型提交内容是不同动作。资料读取继续按当前课程、当前任务及允许范围执行，不默认把账号全库或整课资料放入对话。

## 5. 视频、录播回放与本地保存

- 支持在线播放、提问及主动保存本地；纳入已发布录播和账号可访问的回放，实时直播留待后续。
- 仅导入链接不自动保存整份视频；用户保存后沿用同一条目、进度、问答及成果，保留平台来源并优先本地播放。
- 在线／本地切换、拖动、暂停重开、文件完整性及账号权限变化分别核实；解析到URL、写出文件或进程成功不等于媒体完整可播。
- 视频版本与历史引用保持对应，源地址更新或媒体失联时明确状态，不静默将旧问答改指新资源。
- 模型可见画面仍只限用户确认提交的图片范围和相关已提交历史，不自动补原帧、相邻帧、预览图或裁剪外区域；播放器与下载工具不扩大画面授权。

## 6. 平台字幕、无时间轴文本与ASR

- 平台字幕优先；只有纯文本时明确标为“字幕文本”，不冒充有时间轴的同步字幕，不伪造逐句时间定位。
- 缺少可用字幕时按既定规则取得音频、本地转写；仅导入链接时也允许为字幕处理取得音频，不要求先下载整份视频。
- 当前学习内容优先，其他已导入内容受控排队；支持暂停、检查点、恢复、结果复用与用户手改保护。
- 平台原始内容、ASR结果和用户修订分开保存，字幕格式、语言、时间轴与覆盖据实际取得内容识别。
- 获取失败、无字幕、权限不足与只有无时间轴文本分别说明；当前代码存在字幕封装不代表该封装被播放器实际使用或具备完整返回数据。
- 字幕服务既有附近解惑、时间引用及明确范围的完整整理，不默认整课发送AI、跨课程检索或自动联网补充。

## 7. 课件、附件与章节网页资料

- 纳入可见文档课件、教师附件及章节富文本，保存带来源与版本的本地副本。
- 区分原始文件、平台转换件及图片版PDF，不能把派生PDF或截图标成原始可编辑PPT。必要时沿用OCR及现有阅读能力，不借平台接入缩减既定格式要求。
- 保留文字、图片和公式的实际覆盖与章节归属，缺失、清晰度不足或离线资源不完整时明确提示，不以纯文字片段冒充完整讲义。
- 只处理用户选择且实际可见的资料，不抓取隐藏内容，不自动补视频画面、全屏内容或无关页面。
- 章节资料导入不通过整页抓取夹带第10节排除内容；同名文件或源更新不静默覆盖已有资料、用户笔记及来源引用。

## 8. 课后题目、本人作答与批阅

- 纳入课后可查看的章节练习、驻点题、作业，以及已经批阅且账号可查看的考试记录，支持手动选择具体题目。
- 保存实际可见的题干、选项、题目附件、本人作答和反馈，保留课程、班级／期次及来源版本，供本地重做、错题整理和复习。
- 平台公布答案、由作答推断的答案及AI参考答案分别标识；教师反馈、平台自动判定与AI评价保留来源区别。
- 缺失答案、得分或反馈保持缺失，不由AI补造或记为零；聚合成绩、目录、答题卡入口和题目详情分别核取得内容。
- 课后驻点题不等于接入实时课堂推题，已批阅考试记录不构成在本项目开始考试、创建考试会话或提交答案的授权。
- 当前官网有练习与答题卡读取封装，不等于本人答案、全部题型和教师逐题批阅已经可取；该覆盖仍需按实际权限和响应逐项验证。

## 9. 更新提醒、成果与资产保护

- 后台仅检查已关联课程及所选范围，资料或批阅变化先提醒，由用户选择新增内容或更新版本，不自动导入、覆盖或发送AI。
- 本项目完整保存学习成果及历史，旧问答和成果关联当时的来源版本，不静默改指新期、同名文件或新版素材。
- 平台关闭课程、删除资源、账号失效或连接解除，不自动删除本项目已保存资料、已提交引用、字幕手改和成果。
- 源变化、资源失联、权限不足、检查失败和没有更新分别表示；背景任务服从当前播放、阅读、截图与问答优先及既有受控并发规则。
- 本地成果保存不以平台可连接为前提，本轮不新增向学堂在线自动写回成果的接口。

## 10. 首版明确排除项

- 公告导入。
- 课程大纲导入。
- 课程评分标准导入。
- 考核时间安排导入及考核日历建设。
- 讨论区导入。
- 教师端管理、他人答卷、证书操作及实时课堂功能。

这些内容不作为独立导入资源或自动收集的模型上下文，也不因课程页中存在相关区域而一并采集。题目相关的本人得分和批阅按第8节保留，不因排除课程评分标准而删除个人题目反馈。上述边界为本次学堂在线已确认范围，不替代其他平台各自的明确取舍。

## 11. 接口证据、工具选型与待验证项

[专题调研](../../research/topics/学堂在线官方API与现成工具接入范围调研-2026-10-23.md)保留当前官网公开制品、历史关联项目与旧工具的固定源码依据。本轮没有选定SDK、解析器、插件、发行制品或语义索引方案，没有实际账号响应、媒体或学习体验验收。

| 方向 | 已核依据与后续约束 |
| --- | --- |
| 官方／网页接口 | 未核得当前普通个人自助申请、授权范围完整的官方API；官网内部调用与旧Openplatform文档不能当现行稳定第三方授权 |
| 公共平台与学校 | 相同前端或关联供应商不证明身份、权限或期次互通；学校学堂云／SPOC独立核验，不以替换域名作兼容证明 |
| 课程与资料 | “我的课程”完整性、历史期次、已购资格及各资源格式待账号验证；旧站PDF／HTML分支不冒充新站完整支持 |
| 视频与字幕 | 旧脚本视频下载、纯文本字幕与当前同步字幕分别处理；完整媒体、试看、加密、时间轴和语言覆盖待核 |
| 题目与反馈 | 当前读取封装只作能力线索，响应字段、本人答案、教师批阅及可见性尚未实测 |
| 业务只读 | 显式剔除提交、学习心跳、标完成和重置等操作，包含GET状态改变入口；读取及播放副作用另核，不只按HTTP动词过滤 |
| 工具维护 | 已核开源工具主要停留在2017—2022年；候选作者声明、源码和发行分开核，不将客户端宣传或离线演示当真实SDK |

- 后续依赖固定可交付制品或窄适配接口，不直接启用混合刷课／提交程序，不暴露任意网页、任意代码或无范围文件读取工具。
- 白名单和执行guard落实实际入口、课程、期次及内容范围；学习工具沿用受限读取契约，不恢复按题号／题意自动找题，不因未命中或字幕未就绪自动联网。
- 会话、Cookie、凭据和私人课程资料不进入代码仓库；后端私有管理，不进入模型、前端脚本或日志。
- 请求及结果可对账，防重复导入、过期回调和混淆账号／来源。结果未知先对账，不自动重发或叠加隐式重试；部分成功按实际子项记录。
- 断网、取消、权限变化和重启保留检查点与已有资产，不以全量重新扫描或删除旧资料代替恢复。

## 12. 后续独立验收要求

下表为后续明确启动时的验证方向，不代表已开工或通过。确定性fixture、真实平台／账号、真实模型及实际窗口／学习体验分别报告。

| 路径 | 应验证的结果 |
| --- | --- |
| 平台与权限 | 公共课、已购、历史期次及学校学堂云／SPOC分别核权；会话、课程和来源不混淆 |
| 导入入口 | “我的课程”及分页、课程／学习页链接与期次选择可用，不自动选退课或整课导入 |
| 手动范围与管理 | 章节和具体资料／题目可分别选择，目录顺序、图标预览、改名移动及来源关联正确 |
| 视频与副本 | 在线播放提问、主动本地保存、同一条目进度问答及本地优先播放可用，完整性与试看据实核验 |
| 字幕与转写 | 同步字幕与纯文本身份正确，缺失时音频ASR、暂停恢复和手改保护有效，不伪造时间轴 |
| 资料与富文本 | 原件／转换件／图片PDF清楚，文字图片公式覆盖、OCR及来源版本可核 |
| 题目和批阅 | 课后练习／驻点题／作业／已批阅可见考试分别验证，公布答案、推断及AI内容不混淆 |
| 业务只读 | 包括GET状态改变在内的写行为被guard拒绝，不提交、心跳、标完成或重置；读取副作用有实际证据 |
| 更新与资产 | 仅关联范围提醒并手动选更新，旧引用不漂移，关闭课程或账号失效不自动删本地成果 |
| 排除项 | 公告、大纲、评分标准、考核时间与讨论不被导入或整页夹带，不建设日历或接入首版排除功能 |
| 恢复与数据保护 | 断网、部分获取、未知结果、取消、重启和权限变化可处理，凭据及模型内容范围保护有效 |

当前13场景或上游工具测试不能代替学堂在线独立验收；未验证内容保持未验证，不能用单个旧脚本成功、前端接口存在或原平台打开入口冒充完整接入。实际工期和具体技术选型留待后续明确实施与真实证据确定。
