## 1. 定位、分期与本轮授权

- 以Harness为统一学习入口，连接用户选择且有权访问的雨课堂课后资料、媒体和题目，在本项目内阅读、观看、提问、练习、保存成果和复习。
- **首版以课后学习为主。** 正在进行的直播、同步翻页、实时题目推送及实时课堂自动跟随留在雨课堂，后续另行梳理。
- 当前13场景继续按已有范围与授权交付，本接入不增加为其交付门槛，也不将既有阅读／复习等场景移到后续阶段。
- 2026-10-24更新：后续共用接口收敛、平台独立并行开发、单独验收，不再要求等待B站完成；本次不启动实施。
- **本轮只写入需求并同步文档，先不开发。** 不修改业务代码、数据库、依赖或运行配置，不安装工具／插件、不启动服务、不登录账号、不读取私人课程或下载真实媒体、不运行模型测试。本条不撤销其他聊天已有实施授权。

## 2. 平台端只读与正式课堂动作

- 平台端先只读取和导入本次确认的课后可见内容；本项目保存自己的观看进度、练习和成果，不将本地完成记录冒充平台正式学习记录。
- 不自动签到、加入班级／课堂、发送弹幕、提交答案、同步答案或上报学习完成；正式课堂互动、考勤、考试与提交仍在雨课堂完成。
- **不得为了取得课件或课堂授权，在导入调用链中隐含执行签到或加入课堂。** 若当前读取方法依赖这类动作，应报告阻断与实际缺口，不能把混合自动化工具当作只读连接器启动。
- 会话登录、打开页面、资源读取和媒体播放是否产生业务记录须后续实际核查；GET方法或没有显式签到代码不能单独作为零副作用证明。
- 本项目可正常重做题目、整理错题和复习，复用既有能力；本地作答和AI参考评价不覆盖平台原作答或教师批阅。

## 3. 服务器、学校身份与连接范围

- 接入目标纳入通用雨课堂、荷塘、长江、黄河及学校独立入口，用户选择服务器或填写学校入口，再登录对应账号。
- 各入口分别核验会话、学校身份、课程和班级，不默认共用登录状态、Cookie、资源ID或权限。
- 保留服务器、学校、课程、班级和课次身份；同名课程或不同学期班级不自动合并。
- 学校独立入口逐校验证，不以替换域名作为已经兼容的证据。不同角色能取得的资料分开核实，教师可见或可下载不能直接推为学生可取得。
- 本次不开放教师端管理、他人答卷或全校数据访问；连接目的为本人选定内容的课后学习，不因账号具有额外角色而自动扩大范围。
- 授权失效、更换账号或切换服务器时明确状态，保留本地成果和来源，不静默换身份重试。

## 4. 课程入口、手动选择与资源组织

- 登录后浏览账号已加入的课程、班级和历史课次，同时支持粘贴课程或课次链接；不自动加入新班级，也不因登录或新增内容而自动导入整门课。
- **所有导入可手动分别选择范围**：课程、班级、课次、课件、附件、章节文字、回放／视频／音频和具体题目，不要求全班级或整课导入。
- 导入到用户选择的本项目课程，中间资源管理器保留课程、班级、课次关系，再展示具体资料及其来源。
- 支持来源图标、预览、改名和移动；这些操作只影响本项目，不修改雨课堂原件或班级组织，不丢失原进度、问答和来源关联。
- 选择资料、永久导入和向模型提交内容是不同动作，按本项目已有草稿、提交及受限资料读取契约执行，不因登录就把全课内容交给AI。
- 分页、课次列表及所选子项范围可核对；隐藏、未发布、缺失和未取得内容明确表示，不把第一页或部分可见内容冒充完整课程。

## 5. 课件原件、图片PDF与教师资料

- 纳入已发布且账号可见的课件、教师附件和章节文字资料。
- 能取得原文件时保存原件副本；无法取得原始PPT时，**接受将逐页课件图片合成为PDF导入，并明确标注“课件图片版PDF”**。平台转换件与图片合成件分别标明来源形态。
- 保留原页顺序、课次、来源版本和实际覆盖，沿用本项目OCR及阅读能力支持选取、检索和提问；具体效果后续验证，不把生成PDF等同于文字层完整或公式识别正确。
- 图片版不视为保留原PPT的动画、备注、可编辑文本或公式；页数缺失、清晰度不足、图片／公式／附件缺失时明确提示。
- 只处理用户选定且实际可见的内容，不提前获取教师隐藏页面；不能因内部接口返回更多页面就默认扩大导入与模型读取范围。
- 原文件、派生PDF和OCR结果保持来源关系，不以派生件静默替换原件；用户批注、手改和成果沿用既有资产保护规则。

## 6. 课后回放、教学视频与课堂音频

- 纳入账号可访问的课后回放、教学视频和课堂音频，支持在线播放、提问及主动保存本地。
- 仅导入链接不自动保存完整媒体；用户保存后仍使用同一条目、观看／收听进度、问答及成果，本地优先播放。
- 同一课次存在多段回放时按原顺序分别显示，默认不拼接。回放与课堂课件通过实际课次关联，不把不同片段或新版素材静默改为同一个旧来源。
- 课堂回放、课程内教学视频和独立音频的取得路径、完整性与权限分别验证；教师可下载回放或某个学校LMS脚本可用不能代表所有入口均可用。
- 实时直播不在首版接入范围；获取课后录播不构成自动直播录制、屏幕录制或同步抓取课堂画面的授权。
- 模型只允许看到用户确认提交的图片范围和相关已提交历史，不自动补原帧、相邻帧、预览图或裁剪外区域；课件资源读取也不借机扩大到屏幕或视频画面。

## 7. 字幕与音频转写

- 沿用已确认的平台处理原则：优先获取已有可用字幕，无可用字幕时取得音频进行本地转写；仅导入链接时也允许为此取得音频，不要求先保存整份视频。
- 当前学习内容优先，其他已导入内容受控排队；支持暂停、检查点、恢复、复用与既有临时按需处理规则。
- 平台字幕、ASR原始结果及用户手改分开保存，保护用户修订；语言、格式、时间轴与覆盖据实际取得内容识别。
- 获取失败与确实没有字幕分开显示，权限不足不伪装成无字幕；不默认只取首条字幕就宣称已覆盖全部选定字幕。
- 字幕服务既有附近解惑、时间引用和明确范围的完整整理，不默认全课发送AI、跨课程检索或自动联网补内容。

## 8. 课后题目、本人作答与批阅

- 纳入课后仍可查看的随堂题、作业，以及已经批阅且账号可查看的考试记录，支持手动选择具体题目。
- 保存可见题干、选项、题目附件、本人作答、得分和反馈，保留课程／班级／课次及实际来源版本，供本地重做、错题整理和复习。
- **平台公布答案、由本人满分正确作答推得的答案和AI参考答案分别标识**，不能照搬工具“官方答案”输出栏就认定来源为平台标准答案。
- 教师批阅、平台自动判定和AI参考评价保留区别；缺失答案、得分或反馈保持缺失，不造数、不记成零。
- 工具取得题图、可搜索文本或原试卷文件分别说明，截图归档不冒充完整结构化题库；采用题图时仍遵守获准资料范围，不补取无关屏幕或未提交视频画面。
- 课后可见随堂题不等于接入实时题目推送；已批阅考试记录不构成在本项目开始考试、建立考试会话或提交答案的授权。
- 题目、本人答案及批阅覆盖需按租户、课堂形态和题型逐项验证，不能用作业导出工具一条路径代表所有考试系统均已兼容。

## 9. 更新提醒、成果与资产保护

- 后台只检查已关联课程、课次及所选范围，发现资料或批阅变化后提醒；用户手动选择新增内容或更新版本，不自动导入、覆盖或发送AI。
- 本项目完整保存阅读、观看、练习成果及其历史；平台连接或原件失效不自动删除已保存资料、已提交引用、手改和成果。
- 旧问答及成果继续关联当时使用的来源版本；新课次、同名文件或新回放地址不得静默替代旧来源。
- 资料失联、源内容变化、权限失效、检查失败和没有更新分别表示；背景检测服从当前播放、阅读和问答优先及既有资源调度规则。
- 不向雨课堂自动回写本项目成果。既有本地成果保存与导出能力按原需求保持，本次不新增雨课堂成果写回接口。

## 10. 首版明确不纳入的扩展

- 公告导入。
- 讨论帖、弹幕导入及相应发帖、回复或实时监听功能。
- 签到考勤数据导入、全班统计和成绩排行。
- 考核日历建设。
- 教师端管理、他人答卷及实时课堂自动跟随。

题目相关的本人得分和批阅按第8节保留，不能因排除成绩排行而删除个人题目反馈。上述是本次雨课堂专属清单，不将其他平台的排除项或扩展项自动照搬为雨课堂需求；资料变更检测也不扩大为这些内容的持续采集。

## 11. 接口依据与实施前待核实项

[调研](../../research/topics/雨课堂官方API与现成工具接入范围调研-2026-10-23.md)记录局部工具的固定源码、发行、许可和已知限制。本轮没有选定工具、SDK、插件、登录技术或语义索引方案，也没有核验真实学生会话。

| 方向 | 当前证据与后续约束 |
| --- | --- |
| 官方接口 | 本轮未核得完整、可自助注册的普通个人开放API契约；机构账户／数据对接与学生网页会话分开，不将内部HTTP地址当正式开放授权 |
| 服务器与角色 | 通用、荷塘、长江、黄河和学校独立入口分别验证；固定某域名的脚本不等于全平台兼容，教师与学生可见范围分开核查 |
| 课件取得 | 已有页图转PDF实现，但原始PPT、附件完整性、页数、清晰度和OCR质量仍待验证；旧帮助不能代表2026所有角色的绝对限制 |
| 媒体与字幕 | 指定荷塘回放、某学校LMS视频及旧字幕脚本是局部线索，不代表当前全部回放、音轨、语言或加密方式可用 |
| 题目反馈 | 已有题图／本人答案／平台判分归档实现，但标准答案推断身份、批阅时机及所有题型覆盖须单独核查 |
| 读取副作用 | 部分工具为取得授权先签到或加入课堂；需核实际调用链与网络请求，不能只关闭答题开关就认定只读 |
| 工具复用 | 固定源码及发行制品后再适配，分别核许可证、版本与运行行为；不直接启动混合自动化程序、任意代码桥接或使用作者共享会话 |

- 会话、Cookie、身份凭据和私人资料不进入代码仓库；由后端私有管理，不进入模型、前端脚本或日志。
- 所选课程／班级／课次、资料与模型读取范围由白名单和执行guard落实；不默认放开全库读取、跨课程、自动找题或联网补内容。
- 持久记录实际选择、来源身份、版本、操作及结果；防重复导入、过期回调和账号／租户混淆。结果未知先对账，不自动重发或叠加隐式重试。
- 断网、取消、权限变化、部分获取与重启保留检查点、已有资产及可处理状态，不以重新全量扫描或删除旧内容替代恢复。

## 12. 后续独立验收要求

下表为后续明确启动时的验收方向，不代表已开工或通过。确定性fixture、真实平台／账号、真实模型及实际窗口／学习体验分层报告。

| 路径 | 应验证的结果 |
| --- | --- |
| 服务器与连接 | 各服务器／学校入口、角色、会话及失效状态正确，不跨租户混身份或资料 |
| 入口与范围 | 已加入课程／班级／历史课次列表及链接选择可用，手动选到具体资料和题目，不自动加入课堂或整课导入 |
| 资源管理 | 课程、班级、课次关系与顺序保留，预览／改名／移动不改远端或丢失来源历史 |
| 课件和附件 | 原件／转换件／页图PDF身份清楚，缺页及清晰度据实报告，OCR与引用可核，隐藏内容不被提前取得 |
| 回放与音视频 | 在线播放提问、顺序多段、本地保存及优先播放、同一条目进度恢复可用，音视频完整性分别核对 |
| 字幕与转写 | 平台字幕优先、缺失时音频ASR、链接模式、暂停恢复和手改保护有效，缺失与失败不混淆 |
| 题目和反馈 | 课后随堂题／作业／已批阅可见考试分别核实，题图与文本、本人答案／公布答案／推断／AI解答身份准确 |
| 业务只读 | 不签到、自动加入、发弹幕、提交或上报学习完成；读取调用链的副作用有实际证据 |
| 更新和资产 | 仅关联范围提醒并手动选更新，旧引用不漂移，源删除和账号失效不自动删本地资产 |
| 首版排除 | 不接实时课堂自动跟随，不导入公告／讨论弹幕／考勤／全班统计排行，不建设考核日历，不访问教师管理或他人答卷 |
| 恢复与数据保护 | 断网、部分获取、取消、重启、未知结果和权限变化可处理，凭据与用户资料保护有效 |

当前13场景或上游工具的测试不能替代雨课堂独立验收。未验证项保持未验证，不能因某能力缺少成熟工具就标为通过，也不能用原平台入口冒充已实现的应用内课后学习；工期和具体技术选型留待后续明确实施与真实证据确定。
