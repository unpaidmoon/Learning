## 2. 登录、收藏夹与手动导入

- 支持登录B站账号，读取并展示该账号有权访问的收藏夹及其视频，供用户浏览和选择。
- 收藏夹是可浏览的来源，不是自动导入或持续同步的订阅源。由用户手动选择视频导入，不因登录、读取收藏夹或收藏夹新增条目而自动导入课程。
- 同时支持粘贴普通视频、多P视频及合集链接导入；具体短链、编号和URL变体在后续兼容验证中登记，不预填所有格式均可用。
- 导入后进入本项目的目标课程和文件资源管理体系，保留B站原始来源。用户在本项目重命名或移动条目，不等于修改B站原视频标题或收藏关系。
- 导入链接不自动保存完整视频；用户可主动选择保存本地。平台字幕获取及缺字幕时的音频处理按第6节执行。

## 3. 中间文件资源管理器

- 导入的B站视频链接显示在中间区域文件资源管理器中，作为可持续使用的资料条目，与本地视频采用一致的日常管理体验。
- 使用单独图标区分B站链接／来源，支持预览图、重命名、移动等操作；其他适用行为沿用既有文件管理需求，不建立另一套平台专用资源管理器。
- 多P视频按视频标题建立文件夹，每个分P独立显示，导入时保持原始分P顺序。每P可独立打开、管理、保存本地并记录进度。
- 在项目内重命名、移动或切换在线／本地来源后，原有播放进度、历史问答和来源关联继续归属相应条目，不因路径或标题改变而丢失。
- 链接条目采用何种磁盘格式、目录映射与远程标识存储方式，留给后续实现设计；本轮不指定通过数据库虚拟条目或某种文件扩展名实现。

## 4. 在线播放、提问与进度

- 支持在本项目中在线播放导入的视频，围绕当前内容提问，沿用现有播放器、确认截图、引用、Harness对话及来源回看规则。
- 保存和恢复进度的体验与普通视频一致；在线播放与保存本地后的播放共用同一条目和同一份有效进度。
- **播放进度由本项目维护，暂不主动回写B站观看历史或进度，不要求与B站网页／App双向接续。**
- 文件改名、移动、重开软件或从在线切换到本地后，仍能按有效来源恢复进度；具体来源版本变化与失联状态按既有来源保护契约处理。
- 播放／字幕处理不扩大模型可见画面范围。模型只看用户确认提交的图片范围和相关已提交历史，不自动获取原帧、相邻帧、预览图或裁剪外区域作为输入。

## 5. 保存本地与同一资料身份

- 支持用户主动将视频保存本地，包含纳入范围且实际有权获取的内容；实际可获取能力必须经验证。
- 保存本地后**保留原资料条目，不另增重复的本地视频条目**。本地副本与B站来源关联，默认优先播放本地文件。
- 条目原有名称、课程内位置、进度、历史问答和来源继续沿用；保存本地不是创建新课程、另一个问题来源或第二份进度。
- 需要清楚区分处理中、完整成功、失败、受限、仅试看或不完整。取得封面／元数据、得到下载地址、进程返回成功或生成占位文件，都不能单独证明完整视频已保存。
- 具体画质、编码、缓存／副本位置及下载器候选尚未固定，后续采用与阅读学习和当前执行环境适配的合理默认，再按实际样例验证。

## 6. 字幕优先、缺失时音频转写

- **优先获取B站已有的可用字幕，没有可用字幕时再获取音频、本地转写。** 平台现有字幕可包含可获取的普通CC和平台AI字幕，不能将它们当成本项目本地ASR结果或保证人工校对。
- 对只导入链接、未保存完整视频的条目，用户允许为字幕处理在后台获取音频；无需先要求用户保存完整视频。
- 沿用既有字幕调度：当前观看的视频优先，其余已导入内容受控排队；可暂停，结果持久保存复用。暂停后的临时按需处理与队列恢复继续遵守现有规则。
- 平台字幕、本地原始转写和用户手动修改保留来源区别，后台处理不覆盖用户手改。
- 读取失败、登录态失效、字幕被筛选及真正没有字幕要如实区分，不能静默把空结果当作无字幕。工具实际获取能力、语言和轨道选择在实施时验证。
- 获取后的有效字幕用于既有附近解惑、时间引用和明确选定范围的完整整理；不因此自动把整课字幕加入日常全局检索，也不授权补取视频画面。

## 7. 内容范围与账号权限

本轮明确纳入以下内容，后续按类型分别验收，不预填全部可用：

| 内容类型 | 已确认目标与验收依据 |
| --- | --- |
| 普通视频 | 包括单视频、多P及合集中的相应视频；核实际媒体、字幕和条目关系 |
| 会员内容 | 纳入当前账号有权访问的内容，核实际播放和可保存范围；清晰度／轨道以真实能力为准 |
| 充电专属 | 纳入当前账号具有相应访问权的内容；完整媒体与试看必须区分 |
| 已购课程 | 纳入当前账号已经购买且有权访问的课程；目录、分集和实际可看／可保存范围分别验证 |

不承诺取得账号无权访问的完整内容。试看、缺失分P、只返回元数据和占位文件不能作为完整内容验收通过。某类接入受阻时，报告具体缺口，不自行把已确认的范围降为仅普通视频或把局部通过称作B站整体通过。
