# 学习通平台接入需求收口

2026-10-24补充：共用入口、默认关闭／按需加载、连接与停用、身份／任务／确认规则按[共用准备需求](平台接入共用准备需求收口-2026-10-24.md)执行；本平台的独立责任与验收见[并行开发交接方案](../plans/八平台模块化并行开发交接方案-2026-10-24.md#42-学习通chaoxing)。本平台继续只读，既有功能与排除项不变；本轮仅文档，不开发。

日期：2026-10-23（Asia/Shanghai）。依据：本聊天先调研现成工具与接口，再逐项grilling；用户最终确认“按这个范围收口，写入学习通接入需求文档”。

本文是本轮学习通接入范围的主要需求来源，与[需求总结](AI辅助学习项目需求总结.md)、[13场景需求](13场景学习工作台需求收口-2026-10-23.md)共同理解。实现与验收状态只在[MVP开发计划](../plans/MVP开发计划.md)维护；需求确认不代表接口、工具或真实账号已验证通过。

## 1. 分期与本轮授权

- 以Harness为统一学习入口，连接学习通中用户有权访问的课程与资源，在本项目内继续阅读、观看、提问、作答、保存和复习。
- 当前13场景按原范围统一交付，不将本轮学习通接入增加为其交付门槛，也不挪走原有场景。
- 2026-10-24更新：后续采用共用接口收敛、平台独立并行开发、分别验收，不再要求等待B站完成；本次只确定交接安排，不启动多个平台或本平台实施。
- **本轮只写入需求与同步文档，先不开发。** 不修改业务代码、安装或迁入接入工具，不启动MCP服务、不登录用户账号、不请求真实课程资料、不下载真实媒体、不发出平台写请求或模型测试。
- 本条不撤销其他聊天已有的13场景实施授权，不新增已开工／已通过的学习通工作包。

## 2. 学习通端只读与本项目学习

- 学习通端先只读取和导入：课程、可访问内容、作业与测验、可见批阅记录，以及第8节确认的课表、相关通知和个人云盘。
- 在本项目内可以正常阅读、观看、提问、作答、保存、整理错题和复习；“只读接入”不限制本项目正常保存学习成果和用户作答。
- **不向学习通回填或正式提交作业／测验答案，不将本地练习结果当成已提交或教师成绩。** 正式提交回到学习通完成。
- **本项目保存自己的视频观看进度，不上报或代替学习通正式任务点完成记录。** 需要学校计入任务点的观看仍在原平台完成，用户已接受可能需要回原平台观看的限制。
- 可读取学习通已有的完成／批阅状态；平台记录、本项目观看／练习记录和AI参考评价分别保存与展示。
- 登录方式、会话复用及读取请求是否触发业务状态变化须在实际接入时验证；不能仅凭工具名称“只读”就认定所有页面访问均无副作用。

## 3. 所有导入均可手动选择范围

- 支持浏览账号有权访问的课程与内容；**所有导入均支持用户手动分别选择范围**，不默认全账号、全课程或全库导入。
- 可分别选择课程、章节、文件／文件夹、作业／测验／可查看的考试记录，以及其中的具体题目。课表、通知和云盘同样遵循各自可选范围。
- 导入与当前问题的模型提交是不同动作：导入资料不自动把全部内容送给模型；既有草稿、用户提交、受限来源检索与课程隔离规则继续有效。
- 导入到用户选择的本项目课程，沿用已有阅读、播放、资源管理与练习能力。平台同名课程、不同班级和期次保持区别，不能仅按课名模糊命中就替用户决定来源。
- 记录实际选中范围、来源身份、版本和获取结果；未开放、权限不足、未取得或处理失败的内容明确标识，不能将部分导入标成全部完成。

## 4. 课程资料、章节课件与视频

- 纳入课程“资料”区的文件与文件夹，以及章节内用户选定的课件和视频；两个入口分别核实覆盖，不能只读取资料区就宣称整课资源已接入。
- 文档与课件导入时保存本地副本，保留学习通来源和版本，便于持续阅读、引用、提问与回看。
- 尽可能保留原文件与原有组织关系；实际取得的是原始PPT／Word、平台转换PDF或其他形态时分别标明，不把转换件、渲染结果或截图冒充原始可编辑文件。
- 具体格式与资源兼容性、教师开放／下载设置按真实响应验证；确认支持该资源类别，不等于预填所有学校、课程、格式均已兼容。
- 导入后的文件管理和来源保护沿用既有项目规则；用户重命名、移动本地资料或条目不修改学习通原件，不丢失已保存进度、问答及来源关联。

## 5. 在线视频、保存本地与进度

- 视频默认在线播放，支持围绕当前内容提问，并按本项目普通视频规则保存和恢复观看进度。
- 用户可主动保存视频到本地；导入链接不自动下载整份视频。
- 保存本地后沿用同一资料条目、原有进度和历史问答，保留学习通来源，优先本地播放，不新建重复条目或另一份独立进度。
- 播放进度与学习通正式任务点分开，按第2节执行；本地观看完成不能被标成学校任务已完成。
- 下载、完整性、编码、拖动、进度恢复、在线与本地切换及来源变化均需实际验证；拿到链接、生成文件或进程返回成功不能单独证明完整可播。
- 模型可见画面仍限用户确认提交的图片范围和相关已提交历史，不自动补原帧、相邻帧、预览图或裁剪外区域。

## 6. 字幕与音频转写

用户明确确认学习通视频**沿用B站已确认的字幕处理规则**：

- 优先获取平台已有的可用字幕，没有可用字幕时再获取音频、本地转写。
- 只导入链接、尚未保存完整视频时，也允许为字幕处理获取音频，不要求先下载整份视频。
- 当前观看的视频优先，其余已导入内容受控排队；支持暂停，处理结果持久保存复用。
- 沿用既有暂停后临时按需处理、检查点、原始转写与用户手改分存和手改保护规则。
- 已有字幕、本地ASR与用户修订保留来源区别；无字幕、读取失败、权限不足及其他缺口分别表示，不静默把获取失败当成没有字幕。
- 有效字幕用于既有附近解惑、时间引用及明确范围的完整整理，不增加自动补帧或将整课字幕默认加入日常全局检索。

平台字幕与音频实际可获取性仍须后续验证；本轮是处理目标与范围授权，不宣称相关工具已支持或接通。

## 7. 作业、测验和已批阅考试

- 纳入用户有权查看的作业、章节测验，以及已经批阅且账号可查看的考试记录，均支持手动选择到具体题目。
- 导入时保存题目和可见批阅信息的本地副本，保留来源、版本、对应课程及实际所选范围。
- 题干、选项／附件、用户原作答、教师评分／批注、平台明确公布的答案／解析分别保留；以实际可读取内容为准，缺失字段不虚构、不记成零。
- 平台未公布标准答案时保持缺失。导出工具根据“批阅正确”推断出的答案，或AI提供的参考答案，不得改标成平台原始标准答案。
- 导入后可在本项目重做、整理错题和复习，复用已有练习与复习能力；本地重新作答和参考评价不覆盖原平台作答／教师批阅，也不回填学习通。
- 作业列表、截止日、题量、满分和得分等元信息，与实际题干、附件和批阅内容分开核实；不能用“作业详情接口有返回”代替题目导入成功。
- 阅读已批阅、可查看的考试记录，不表示授权在学习通开始考试或提交答案；正式操作继续在原平台完成。

## 8. 课表、通知与个人云盘

### 8.1 课表

- 纳入课表只读查看。
- 支持按选定课程、周次等范围导出日历文件，保留实际日期与学校节次；不以本地猜测值冒充学校时间。
- 导出日历文件不等于向外部日历账户自动创建事件；本轮不新增日历双向同步。

### 8.2 相关通知

- 纳入课程、作业和考试相关通知的只读展示，可获取的通知内容与附件由用户手动选择导入。
- 保留来源和原文入口，可关联对应课程；只取得摘要时明确是摘要，不冒充完整通知。
- 相关通知导入与下一节的后台课程变更检测是不同动作，不因存在通知就自动导入其内容或附件。

### 8.3 个人云盘

- 将个人云盘作为可选导入来源，支持浏览并手动选择文件或文件夹。
- 导入用户指定课程时保存本地副本，保留云盘原来源，不自动全库导入或修改云盘原件。
- 文件夹和分页范围、可见文件数与实际导入结果必须可对账，不将工具返回的第一页当成完整云盘。

## 9. 已关联课程的后台变更检测

- 用户允许后台检查**已关联课程**的新增资料、新作业和内容变更，并予以提醒。
- 只检测并提示变化；新增内容仍由用户手动选择导入，不自动覆盖已有本地资料、用户笔记或历史问答，不自动把新内容交给AI。
- 课程修改后的内容与已导入版本区分，历史引用不得静默指向新版。再次导入后的具体版本组织在后续设计中确定，保留原有来源保护要求。
- 账号失效、权限变化或检查失败应与“没有更新”区分。检查频率和调度服从既有前台优先与后台资源规则，不直接照搬上游工具的全课程扫描或固定轮询默认值。

## 10. 工具证据、待验证与验收

[工具与接口调研](../../research/topics/学习通接入工具与接口范围调研-2026-10-23.md)记录官方OAuth、只读MCP、章节PDF／题目导出器和资料／媒体候选的固定源码证据。它是选型依据，不表示已选定工具、可原样接入或真实账号已通过。

后续验收分别核实以下闭环，本轮未执行：

| 范围 | 必须核实的行为 |
| --- | --- |
| 登录、课程与范围 | 本人可访问课程正确，班级／期次不串读，所有导入可手动分别选范围 |
| 资料区与章节资源 | 所选文件／课件／视频实际取得，原件／转换件身份清楚，缺口不冒充完整 |
| 文档和题目保存 | 本地副本可重开、来源和版本可回查；题目、原答、教师反馈及答案身份分开 |
| 视频 | 在线播放、提问、进度恢复、同一条目保存本地与本地优先播放可用 |
| 字幕 | 平台字幕优先，缺失时音频转写，当前优先、暂停、复用及手改保护有效 |
| 作业／章节测验／已批阅考试 | 范围选择与实际题目匹配，本地重做／错题／复习可继续，缺失答案保持缺失 |
| 课表／通知／云盘 | 分别支持已确认的查看、选择与导出／导入，时间、正文范围及分页不伪造 |
| 后台检测 | 仅已关联课程，变化提醒不自动导入／覆盖／发送AI，失败与无更新分开 |
| 只读与正式状态 | 不回填／正式提交、不上报任务点；本地学习和学校正式状态清楚区分 |
| 恢复和资产保护 | 账号失效、断网、来源更新／失联、取消重开可处理，未知先对账、不自动删除用户资产 |

确定性fixture、真实平台／账号、真实模型、实际窗口和学习体验分别报告；未验证项保持未验证，当前13场景的技术证据不冒充本平台接入已验收。本轮不指定解析引擎、登录技术、精确同步频率或未经验证的格式全覆盖承诺。
