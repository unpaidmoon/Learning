# V5 执行方案：PDF/Office实际格式与原页引用

更新日期：2026-10-20。状态：**格式与失败矩阵已编写，代表文件/固定转换闭包待准备，未执行。** 工作包：C-02；依赖来源/附件基础，应用集成关联D-02/C-03。

共同规则：[验证入口](README.md)。依据：需求0.18/3.1/4.4，审查F04/F10/F15及[技术选型](../architecture/AI辅助学习项目技术选型方案.md)。

## 1. 目标与实现顺序

先PDF，再PPT/Word。PDF.js显示原页，文字层/区域选择形成自有引用；Office优先Harness Office provider/LibreOffice Kit转换为版本绑定PDF预览，独立LibreOffice只作为有失败证据后的兼容后备。两种转换共用同一接口、任务、缓存和来源版本，不能维护两条业务真相源。

扫描页的确认区域图片提问与OCR文字选择分开。完整首版需支持扫描资料的可用选取问答，但本轮不自动加“所有扫描字均可精确文本选择”的新承诺。知识库解析/召回及自动找题不作为本方案交付。

## 2. 前置检查

| 前置 | 要求 |
| --- | --- |
| 授权与素材 | 用户主动提供/批准的实际资料及允许操作、图片查看范围；合成页面可供自动截图，真实页超出所选范围不得自动传给编码模型 |
| PDF组合 | 固定PDF.js版本、匹配worker、本地字体/CMap等资源和浏览器组合；后端PDFium/Docling按实际需要选，不一并装齐 |
| Office组合 | 精确Kit/原生包/runtime/VC++版本、来源、hash和许可闭合；历史默认provider缺包失活不能当转换通过 |
| 版本差异 | 既有Harness锁Kit0.1.5，公开Kit部分master文档仍0.1.3；执行用对应制品/源码核实配置，不复制不匹配说明 |
| 任务与权限 | 受控转换进程/取消、文件类型/来源版本/目录授权；不向模型开放任意path或通用视频解析 |
| 参考 | 人工可核原件显示/导出页作为保真对照；参考来源和是否安装Office记录，不要求用户自行搭开发环境 |

原生PDFium不能在线程中任意并发调用；选择受控串行或进程隔离，记录实际方案。转换不启用任意宏/主动内容，不因文档外链静默访问网络；需要的安全隔离按固定组件实际能力验证，不能只写“禁宏”就宣称完成。

## 3. 素材矩阵

| ID | 素材/格式 | 必核能力 |
| --- | --- | --- |
| DOC-P1 | 文字PDF，中文+公式+图形、多页 | 文字层顺序/选区与原页、区域图清楚，页序/页面标签区分 |
| DOC-P2 | 扫描PDF，公式/题图、小字、旋转页 | 原页显示/缩放/区域提问；不能按无文字层误报空文档，也不能冒称OCR文字可选 |
| DOC-P3 | 混合PDF/不同页面尺寸 | 有文字页与扫描页分别处理，选区坐标/来源正确 |
| DOC-W1 | DOCX，中文字体/数学公式/分页表格图片 | 转换保真、分页/来源映射，不把预览页等同原生Word精确页 |
| DOC-S1 | PPTX，公式/图形/备注/隐藏页 | 可见内容与备注/隐藏部分区分；预览与来源页对应，不能静默把备注当可见题干 |
| DOC-W2/S2 | 旧DOC/PPT，限用户实际需要 | 逐格式证据，不能用DOCX/PPTX通过代替 |
| DOC-E1 | 缺字体、损坏/加密/不支持文件 | 可处理错误；缺字诊断为空不保证保真，不能假成功 |
| DOC-E2 | 改名HTML/RTF/WPS/伪扩展名，嵌外链/异常对象 | 类型不符明确拒绝或声明支持路径；不自动外发/执行主动内容 |

每类先少量代表文件；未提供的实际格式保持未覆盖，不为了覆盖表格下载用户无关资料。

## 4. 执行步骤与用例

1. 记录原文件hash/版本/字节、参考页和允许选取区域；只登记原路径，不默认复制原件，测试副本仅在授权临时区使用。
2. PDF先在锁定阅读链打开；Office先核provider实际激活，再做转换。记录转换依赖、耗时、占用、缓存键和错误。
3. 人工逐个核代表页的公式/正负号/上下标/字体/图形/表格/换行，不能只看首屏有内容。
4. 选文字/框区域→预览→加入草稿→保存引用→回来源；缩放/旋转/窗口调整后再选，核源坐标，不保存CSS像素当原页坐标。
5. 运行下表失效/失败/取消用例；再集成到多窗口，确认选区与拖拽、播放器状态无冲突。

| 用例ID | 操作 | 通过条件 |
| --- | --- | --- |
| V5-01 | DOC-P1/P2/P3原页显示与选择 | 文字/扫描分验，用户选取内容与原页一致，图像细节可用 |
| V5-02 | DOC-W1/S1及实际旧格式转换 | 人工对照数学内容无静默缺损，格式分别记；UI不假称全部Office兼容 |
| V5-03 | 页序/标签/印刷页码、引用区域与旋转 | 明确坐标与页身份，回看定位正确；无法识别印刷页码不猜 |
| V5-04 | 转换中停止/超时/组件失败 | 任务有实际终态/错误，临时文件/所属进程可清理，不误杀其他Office/Harness |
| V5-05 | 原件转换中或之后改版、同名替换 | 版本复查，旧预览不发布给新版本；旧聊天引用仍绑旧版/快照 |
| V5-06 | 移动/删除源文件后回看旧引用 | 已保存引用/截图保留，来源不可用明确；不静默跳同名新版 |
| V5-07 | 文档工具收到视频ID/任意路径/越权课程 | 类型/业务授权/guard拒绝；不能借解析器的视频关键帧能力补图 |
| V5-08 | DOC-E1/E2与外链/主动内容 | 错误明确、无任意网络/代码副作用；失败不伪装空白预览成功 |
| V5-09 | 多窗拖动/缩放，遮挡播放，引用后重开 | 选区/草稿/来源不丢，视频按已确认状态播放，不因遮挡卸载 |

可用合成quote/fixture检查提交路径；真实文档问答按项目级长期模型调用授权自主执行，不再另申请调用次数或费用额度，仍需具备对应任务和素材范围授权；数学效果与转换保真分别报告。

## 5. 通过、失败处理与证据

每种所需格式保留原版本、预览hash/页映射、人工保真检查、选区/导出内容、来源回看、错误/取消和资源结果。扫描区域通过不能填扫描文字选择通过；Office元数据/激活通过不能填转换保真通过。

关键数学缺字/公式变化/错页、源版本混用或越权读取即该例失败。先排依赖/字体/转换参数与坐标；仍无法支持核心实际资料，才对照独立转换候选并给用户最小格式/投入取舍，不自行取消Word/PPT。

不承诺所有扩展名/编码/排版。输出实际支持/失败/未覆盖清单、精确制品闭包/许可及改动；C-02按对应范围实证更新，知识库C-03仍需其任务验收。
