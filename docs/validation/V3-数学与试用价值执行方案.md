## 1. 要验证的收益

核心收益是减少“暂停→截图框选→找图上传→切浏览器→提问→等待读完→返回视频全屏播放”的负担。用户通常读完才返回视频，不能按发送后立即继续看设计比较。

数学效果、操作收益、等待与维护分别报告。不给准确率先验、学习成绩承诺或固定节省比例；集成界面不自然提高模型推理能力。

## 2. 前置与分组

- A-01—06主路径可运行，V1真实接入及V2关键资产/重复执行问题已解决；无法运行只记录前置缺失，不做假聊天验收。
- 固定应用/制品/配置，用户模型与思考实际生效；允许范围内的图片/引用、课程/来源版本和人工预期明确。
- 用户主动确认真实题图/手写及允许编码模型查看范围；自动UI质检仅合成fixture，不自动拍真实视频全画面。
- 用户已给予项目级真实模型调用长期授权：V3任务获准执行后，按验证需要自主调用及必要复测，不再设首轮24次等人为总次数或固定费用额度，不逐批确认预算。模型/思考尊重用户选择；单次输出和观察时限按具体技术需要记录与调整，采集不含凭据。所有初始、追问、摘要/工具续答/内部替换仍统计实际出站；非必需辅助关闭，未知执行先对账。
- 合成18案例为链路基线，真实网课、纸笔和综合题要分别标识；未收到素材就留未覆盖，不用打印文字冒充手写。

| 组 | 控制与作用 |
| --- | --- |
| UI操作对照 | 同一使用者、相同题材/回答内容与阅读任务；确定性回答可用于隔离操作差异，但必须标fixture |

## 3. 操作步骤

1. 执行前选定样本/回合清单、人工预期、输入和配置，按实际模型请求预计数冻结预算。记录普通题/复杂证明/资料查询分类，缺样本明确。
2. 先用合成视频/图像走完整操作，核坐标、确认范围、草稿与播放，不读取真实画面给质检工具。
3. 在真实学习由用户主动截图/确认后，经业务层发送；记录真实增量和有用内容时刻，用户保持正常阅读，不因计时强制返回视频。
4. 正常回答后局部追问，明确纠正条件；观察历史、题图/修订、工具与来源。至少一个活动停止后再追问；若当次过快无法活动停止，记未覆盖而非通过。
5. 切课程/收放/全屏/同课程换资料/重开历史，核对话身份、部分回答、附件和草稿。与V2共享证据，不为同一失败重复造测试体系。
6. 经过数次实际使用后，汇总操作、模型、保存与维护记录，由用户判断是否愿意继续日常使用，再复核完整首版投入。

## 5. 时间、质量与价值记录

| 指标 | 起止/定义 |
| --- | --- |
| 截图操作 | 截图动作→确认产物进入可发送草稿 |
| 传输首增量 | 点击发送→收到第一个真实内容增量，仅诊断 |
| 首次有用内容 | 点击发送→足以继续学习的实质内容；状态/复述/套话/thinking不代替教学解答；后来推翻的内容不计成功 |
| 完整回答 | 点击发送→实际终态，可与阅读并行但单独记 |
| 返回播放 | 用户读完/点击关闭聊天→恢复所需播放状态 |
| 完整流程 | 从暂停截图到读完、恢复全屏继续；含找图/切软件与必要返工 |
| 正确与维护 | 每例错误分类、修改/重复提问、保存/恢复/排障时间；区别首次集成工作与日常负担 |

10秒是普通问题有用内容的体验目标，复杂证明、资料查询另评，不设所有请求统一硬截止；观察实验上限另记。只报实际样本的逐例结果/观察分布，不从少量结果宣称p95。

## 6. 退出与失败处理

试用最小门槛：真实主要操作、数学样本、保存与活动停止有证据；无严重权限/数据/重复派发问题；多次实际使用稳定少操作且用户愿意继续。部分普通题超10秒不单独否定交付，数学错误也不能因为速度达标而隐去。

每例错误都保留；同类关键失败修正后复测原例与至少一题不同同类样本，再失败记录未解决适用性，由用户判断是否适宜日常使用。不要把模型自评或另一个模型评分当标准答案；数学核查是验收活动，不变成每次问答的常驻复核流水线。

若原裁剪清楚但请求图失真，修图像链；条件读对而推理错误，评模型/思考及题型适用性；更正丢失修快照/压缩；工具错误修范围/覆盖；操作收益被维护/等待抵消时先复核投入，不自动删首版能力。

交付逐例记录、操作对照、真实学习观察及未覆盖，给出“可试用/修复后再试/证据不足”的判断，不伪造完整首版或数学准确率验收。
