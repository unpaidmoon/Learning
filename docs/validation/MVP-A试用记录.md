# MVP-A 人工试用记录

本表记录正常学习体验，不是已经通过的验收。自动技术证据见 [MVP-A 与 V3 报告](../../research/reports/v3/MVP-A与V3验收报告-2026-10-21.md)。不必为测试增加题量；按自己的学习节奏使用数次，再判断是否愿意继续。

## 操作入口

1. 在已有项目环境中双击根目录 `启动学习.cmd`，等待学习页打开。选择或新建课程，点击“选择本地视频”主动关联原件；也可展开路径入口。不复制原视频，进入课程也不自动打开旧资料。
2. 点击视频播放、跳转。遇到需要提问的题目，点击“截图提问”，视频会暂停。缩放、移动并框选自己愿意提交的范围，确认后直接加入草稿；取消保留原文字和其他附件。
3. 补充文字并发送，或粘贴已选图片后逐张确认。默认配置是已验证的 `deepseek-flash / high`；模型与思考可以手动改变，Pro 仅文字，不会自动替换选择。读完答案再按自己的节奏追问；明确更正可写在问题或更正栏中。
4. 回答仍在生成时可以“停止回答”，已收到部分会保留；停止后继续追问。可保留当前题图，只修正错误条件。不需要重新截取原画面。
5. 收起／展开聊天、同课程切视频、主题和全屏不会新建对话；沉浸问答结束后收起聊天会恢复视频全屏并续播。换课程时原生成继续，仍归属原聊天。
6. 关闭网页后后台继续；重开网页后选择课程并主动点开历史，可接续保存内容。结束本次后台时点“安全退出”，有活动回答会先确认。

真实视频播放不意味着编码助手可以查看完整画面。请只提交自己确认的题目范围；原图留本机供重裁，回答模型只获得确认选区、文字和相关已提交历史。若需要向编码助手反馈识图问题，请另行明确给出允许它查看的选区，不提供裁剪外画面。
