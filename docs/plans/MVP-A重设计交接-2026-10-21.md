## 已确认的目标

### 官方 Harness 接入

- 直接复用 Harness 官方功能，默认官方账号登录，同时提供 API Key 方式。
- 账号授权、凭据管理、模型目录和额度状态优先复用官方实现；API Key 由用户主动选择，账号失败／额度不足不隐式切换凭据方式。
- 现代码使用 API Key 路线，`harness/profiles/learning.patch.json` 关闭了 `account-controller`、`deepseek-account`、`llm-deepseek-account`。需按实际固定制品核查并接通，不能只加一个没有后端能力的登录按钮。
- 官方账号路线存在不等于当前组合已验证，也不保证账号实际额度／模型准入。官方授权需用户操作时，先交付可操作的入口，再请求用户实际登录；不索取账号密码、Cookie 或 token。
- API Key 仍遵守当前私有配置规则；账号 token 由官方 Harness 管理，内部凭据不得进入公共业务 DTO、前端构建、模型提示或日志。

### 课程文件资源管理器

- 左侧栏顶部切换课程，下方显示当前课程真实根目录及子目录的文件树；中间区域用于资料标签页，同一时刻只展示一个文件。此处按用户在实施聊天中的再次明确纠正，替换原“中间资源管理器”的位置描述。
- **每课程一个真实本地根文件夹，原始资料必须位于其中。** 位置由用户选择，已有课程文件夹可直接使用。取消多个外部文件夹关联方案，不用软链接替代导入。
- **课程名与根文件夹名绑定**：软件中重命名课程，同步重命名根文件夹。
- 外部资料**默认移动**进入课程目录，用户可主动选择复制；已经在课程目录内的资料不重复复制。
- 同名冲突询问保留两份、跳过或明确替换，不自动覆盖。
- 支持真实磁盘整理：重命名、移动、新建文件夹等；“从课程移除”与“删除磁盘原件”明确区分。
- 改名／移动维护稳定资源身份和引用，内容替换按来源版本处理。旧题图和引用不得静默指向新内容，模型工具仍只读。
- 已支持的格式在软件内打开，其他格式提供用户主动使用系统默认程序打开的入口。文件列表不能伪装 Office／ASR／知识库已经接通。
- **不得为了适配新规则自动搬运既有真实视频、课件或用户资产。** 现有数据的兼容／迁移必须可审查，用户实际选择导入或迁移的动作与范围才是操作依据；测试用合成文件。

### 标签页与视频状态

- 可打开多个资料标签，**同一时刻只展示一个文件**。
- 自由移动、并排和叠放的内部多窗口需求已明确撤回，不留作默认后续目标。
- 切离视频标签自动暂停并保存位置；切回恢复切走前的状态：之前在播则续播，之前已暂停则仍暂停。
- 同课程换文件／标签、收放 AI、进出全屏不创建新聊天；切课程时旧生成继续并归属原聊天。原有“进入课程不自动打开上次资料”等未被更改的规则保留。

### 全屏问答

- 用户要的是**全屏看视频时仍可唤起 AI**，不是常态工作区增加一个收起课程目录的按钮。
- 唤起 AI 同时提供独立快捷键和鼠标触边入口，入口平时不常驻。
- 唤起后仍为全屏工作区，左视频、右当前 AI 对话，课程目录隐藏；关闭 AI 后恢复纯视频全屏并继续播放，同一对话保持。
- 普通唤起／发送／追问不强制暂停视频。
- 删除视频下方单列的“播放视频／截图提问／视频全屏”三个按钮；保留相应播放和全屏能力。

### 截图

- 快捷键只在本软件内生效，包含全屏；不是 Windows 全局截图。
- 可框选本软件内**全部可见内容**，包括视频、文档和 AI 回答。不能用仅截视频帧的旧流程冒充全软件范围。
- 触发时暂停视频，按住鼠标确定起点、拖到另一对角、松开完成；不强制先进入独立裁剪器。
- 松开后选区图片直接加入当前对话草稿，自动展开右侧 AI、聚焦输入框；用户补充文字后自行发送，不自动调用模型。
- 不额外另存到桌面、下载或独立截图目录，截图附件随聊天数据保存。保留已有文字、引用和其他附件；原图供本机重编辑，不因此获得模型可读权限，重编辑不能补原帧或附近画面。

### 鼠标选区引用

- 在回答中用鼠标选择文字／公式，点击选区旁临时浮出的“添加到对话”才加入当前草稿。
- 普通选中、复制不自动加入；取消逐条公式的常驻引用按钮。
- 使用可单独移除的引用卡片，显示所选文字、渲染后的公式及来源。补充问题仍在文本框，不把卡片直接转成待编辑 LaTeX。
- 实现必须对应真实所选范围，不能退回按钮引用整式来冒充鼠标选区。复杂公式范围／源码映射需据实际目标验证，不声称仅有 KaTeX 就已经完成，也不自动增加 OCR 或常驻复核模型。

### 播放控制

| 操作 | 行为 |
| --- | --- |
| 空格／单击视频画面 | 播放／暂停 |
| 双击视频画面 | 全屏／退出全屏 |
| ESC | 退出全屏 |
| 短按键盘 ←／→ | 快退／快进 2 秒 |
| 长按键盘 → | 临时 2 倍速，松开恢复原倍速 |
| M | 切换静音 |
| 全屏视频区域滚轮 | 调整音量 |
| 非全屏悬停音量控件并滚轮 | 调整音量 |

全屏 AI 区域滚轮正常滚动聊天；文本框输入时空格、方向键与 M 不被播放器截获。短按／长按及单击／双击要区分，不能叠加误操作。具体截图／唤 AI 组合键、音量步进、长按阈值未被指定，可按工程与实际交互验证选默认值，不重复询问已确认原则。
