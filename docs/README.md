新增文档先选择用途归属；持续维护的规范通常不加日期，单次研究与验收报告保留日期。目录使用英文小写，说明文档可以使用中文文件名。相同事实只维护一个主要来源，其他入口简述并链接；文档内部引用使用相对路径。

生成 API 来自正式源码及 [OpenAPI](../contracts/openapi.json)，不在设计说明中另写一套字段定义。报告中的历史命令和原运行路径按形成时理解，当前入口与迁移后验证范围见迁移记录。
