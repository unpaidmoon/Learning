# V1 执行方案：Harness 学习组合的最小路线

更新日期：2026-10-20。状态：**方案已编写，runner/profile/fixture待实现，实验未执行，执行授权待取得。** 本方案只做隔离接入判定，不初始化正式应用。

共同规则、记录位置、模板和授权边界见 [验证入口](/D:/Codex/Learning/docs/验证/README.md)。工作包：P0-00；问题依据：审查F01—F05、F14—F15。现有probe只可借鉴连接/清理方式，不直接改成产品。

## 1. 要回答的问题

1. 固定Windows Web Host在不展示官方UI时，能否让确认图与文字真正进入视觉模型，收到终态前的真实增量？
2. 活动生成是否能通过单会话cancel停止，同对话随后可继续？
3. 请求、事件、部分文本和终态能否清楚归属、恢复，未知执行不会再次派发？
4. 工具/外发/图片边界及缺失usage能否落实？需要多少配置、窄适配或上游补丁？

不验证正式UI、整课ASR、Office、完整知识库或Android。一次组件通过不等于用户学习闭环通过。

## 3. 经授权后才实现的最小验证件

| 独立runner | 以参数列表和隐藏窗口启动本次宿主，维护Job/实例归属、就绪/总时限、端口和清理；不接管其他Harness实例 |
| 学习profile/配置覆盖 | 无coding persona、任意shell/read_image/补视频帧/浏览器旁路；关闭无关标题/摘要/网页、日志和包清单外发；列实际工具而非只看YAML |

| Peer适配 | 私有token交换Cookie、唯一生命周期WS、正确Remote envelope；先follow取得基线再prompt；从snapshot/page重建，不能填虚构afterCursor |
| 出站计数/预算guard | 在实际网络派发前统一编号和占额度，覆盖内部替换及辅助调用；A拒绝所有非本地模型目标，B只允许批准的官方目标与必要端点 |
| 输入/结果观测 | 本地受限比较原裁剪、规范化副本、请求图；raw字段存在性和Harness投影可关联attempt，采集最少必要内容 |

## 4. 操作顺序与用例

### A：本地确定性阶段，真实模型请求上限为0

1. 填写run-record，核允许目标、清理边界、临时目录、资源上限和依赖；启动前证明非本地模型请求会被阻断。
2. 启动本地fixture，再启动隔离Web Host；记录版本、就绪、激活项、工具/实际系统内容摘要和未激活项。不可用的必需插件先处理，不忽略警告宣布成功。
3. 建立Peer和生命周期WS，创建会话，follow拿baseline，随后发带已确认合成图的prompt。HTTP envelope沿固定契约实现，不套SDK JSON-RPC。
4. 执行下表；每个独立fixture用全新case状态，恢复用例保留规定的同会话。故障仅作用于本次连接/fixture，不改系统网络。
5. 检查取消后同一宿主仍可接受新问题；保存证据、清理所属进程/端口。A失败不进入B。

| 用例ID | 触发/输入 | 必须观察到的结果 |
| --- | --- | --- |
| V1-A01 | IMG-SCOPE确认裁剪，内外不同标记 | 请求图只含选区，无未确认附件/原帧；工具不能读取外部标记 |
| V1-A02 | fixture按顺序发文本/公式片段后等待，再终态 | 终态前就收到相同顺序的实际增量；不是收全后重播 |
| V1-A03 | A02保持活动时调用session/cancel | fixture观察取消/连接中止或宿主取消证据，Harness进入实际终态；部分内容保留，单纯关闭follow不算 |
| V1-A04 | A03后同会话新prompt | 正常新生成可归属，不残留取消/旧增量污染 |
| V1-A05 | 已接收请求后丢回执、首增量后断线 | 先查询原会话/事件；不能自动第二次模型请求；不可确认保持unknown |
| V1-A06 | 断开Peer生命周期，再连接/follow/page | 旧凭据按契约失效，重建baseline并去重；业务身份不靠最后回答猜测 |
| V1-A07 | 完整、缺input、缺output、明确0、累计usage/重复回放、结束前断流 | 缺失和0区分，累计只结算一次，raw/provenance可追；缺终态保留未知 |
| V1-A08 | 新图选纯文本模型；旧图历史再切纯文本模型 | 新图清楚拒绝；旧图占位/能力变化不误报“仍能看图”；记录真实选择生效边界 |
| V1-A09 | 工具请求原视频帧、任意路径、其他课程、资料伪指令、scope新注册旁路 | schema/guard/工具内部身份校验共同拒绝；不允许的工具body执行次数为0 |
| V1-A10 | 慢工具观察abort；一个故意忽略signal的受控fixture | 合作取消正常；忽略signal时由IO/所属子进程边界结束，不宣称timeoutMs本身强制结束，不杀宿主 |
| V1-A11 | 缩短fixture上下文预算触发compaction/offload，保留更正后的当前题 | 业务选定当前题图/条件/修订仍可核；无语义保护则记录缺口，不能以业务历史还在代替有效上下文 |
| V1-A12 | 触发标题/摘要/重试/文件过期替换的受控路径 | 所有模型派发均能观测；独立预算guard能拦截超额，不只依赖maxRetries=0 |

A11仅证明构造路径与上下文内容，不证明真实模型记忆/推理。工具中的课程/版本/附件ID为fixture业务身份，不要求在V1先造完整数据库。

### B：少量真实模型阶段

拟定预算：**最多6个实际出站模型请求attempt**，包括辅助、工具续答、provider内部替换等全部模型派发；每次输出上限候选8192，单次观察上限180秒，执行前核有效映射。无自动重试；非必需辅助调用关闭。到额先阻止新派发，已发请求取消/对账，缺用量保留未知。以上是待授权实验参数，不是日常产品限额/统一超时，也不覆盖用户模型/思考选择。

| 次序 | 用例/会话 | 输入与观察 |
| --- | --- | --- |
| 1 | V1-B01 / C1 | M01确认题图＋文字；极限预期1/3，核实际请求图/公式、真实增量/终态 |
| 2 | V1-B02 / C2 | L02确认矩阵题图；核矩阵与特征值，事件不串C1 |
| 3 | V1-B03 / C3 | H02题目＋用户主动提供的手写过程；要求检查错误，核链式法则和卡点 |
| 4 | V1-B04 / C1 | 明确“刚才分母应是2x³，其余不变” |
| 5 | V1-B05 / C1 | 要求按更正后的题目详细推导，确认真实处于活动生成后停止；保存已有内容与终态 |
| 6 | V1-B06 / C1 | 停止后追问“按更正后的分母解释泰勒展开为什么可用”；预期极限1/6，更正保留、会话仍可继续 |

B04预期直接按新条件得到1/6，不固定再确认；B05必须实际活动时取消，若模型结束太快没有活动取消证据，标未覆盖，不静默加请求。手写未提供则B03未覆盖，不能用打印字冒充手写。某内部调用占用额度导致计划场景未做完时如实记录，禁止自动加额或省略辅助调用计数。

真实调用前检查有效工具/外发配置，绝不为提高成功率自动补视频帧。截图图像可为用户确认的合成题图；此时结论只限真实模型＋该输入，不冒称真实网课UI闭环。

## 5. 必留证据

- 制品/依赖/profile hash、实际激活工具、有效模型/思考和输出限额；私有系统内容本地保留摘要，不输出环境凭据。
- 按实际派发记录request/attempt、会话/提交/事件水位、首增量/活动取消/终态时间，和预算guard拦截记录。
- 用户确认范围与三层图像的本地受限引用、尺寸/类型；普通日志不存图像base64。
- usage原始可得字段、字段存在性、归一化、来源和结算ID；未知与原始0分开。
- 每例passed/failed/not_run/unknown，实际数学内容/人工判断，必要补丁清单和维护代价；启动/资源/清理仅报本次样本。

## 6. 通过、失败和后续

A中越权拒绝、未知不重发、实际增量、取消/恢复和计量负例通过，才可进入B。B的图像可用、真流、活动停止后继续及配置生效有证据，才能支持Web路线继续；单例数学错误必须记失败，根因分图像/推理/上下文，不能用源码存在代替效果。

分开下结论：传输/权限/状态、图像接入、数学样本及未覆盖。A通过不等于B通过，B通过不等于正式UI或日常使用验收。

发生越权输入、未知重复请求、错误归属、预算计数失效立即停止真实组。先修组合/依赖/窄适配；只有主线确实受阻才对照SDK桥接，不搭建另一条正式直连主线。广泛核心分叉、无法可靠停止/计量或基础数学持续失败时，形成“证据—影响—最小替代”，建议用户重决策，不能自行扩范围。

完成后只有P0-00/V1可据证据更新，P0-01—04及应用仍未完成；恢复构建须另有明确授权。
