## 1. 假设与边界

比较两条候选：A＝KaTeX排版＋项目维护的结构/源表达映射；B＝MathLive只读mathfield及公开selection/getValue接口。MathLive 0.111.1、源码30ad20a7a47ea43a2f6915808023202c78f37742是既有核验候选，非已采用版本；KaTeX沿既有链固定实际兼容版本。

目标是用户可用鼠标选符号/子式，看到正确预览并加入草稿，来源与消息修订可靠。不会默认引入完整数学编辑器、计算引擎、模型OCR或两套长期渲染链。MathLive的结构range不是原始LaTeX字符偏移，不能先承诺输出字节完全相同。

## 2. 前置与页面

- 获得隔离页面/必要依赖准备及浏览器验证授权；无真实模型/视频需求，无需凭据。
- 固定两组精确版本与构建依赖，使用相同中文正文、容器、字体大小、主题/缩放/样本；记录各自实际产物与依赖，而非peer声明。
- 最小页面仅包含只读回答、公式ID/消息修订、选区预览、加入/移除草稿、整式/整步快捷引用。明确fixture，不冒充正式问答UI。
- 测试数据全合成；浏览器截图可用于该合成页面，不读取真实屏幕/网课。
- 禁止任意HTML、危险宏/URL或可执行扩展；只读控件的键盘、菜单、焦点行为可控，不静默开启外部资源。

## 3. 冻结的合成表达与选择目标

| ID | 原始表达 | 具体目标/预期 |
| --- | --- | --- |
| F01 | (x+1)/(x²+1)，实际用LaTeX分式呈现 | 分别选分子x+1、分母x²+1、分母的x或指数2；不能只允许整分式 |
| F02 | aₙ₊₁²+aₙ² | 选单个a、下标n+1、第一项的上标2、完整第一项；上下标归属不串 |
| F03 | √(x²+y²) | 根号内x²一项、完整被开方式；是否含根号应与可见选区/预览一致 |
| F04 | 从0到1积分x² dx | 选上限1、下限0、被积式x²、dx；不自动扩成整积分 |
| F05 | 矩阵[[a,b],[c,d]] | 选单元素b、第一行、第二列；不连续列若支持须清楚预览，不能把另一列混入 |
| F06 | 分步推导：(x+1)²=x²+2x+1；下一行代入x=1 | 选2x、一整行推导、两行文字/公式混排片段；表达与消息位置可回查 |
| F07 | 中文“当x>0时，ln(x²+1)的导数为2x/(x²+1)” | 选文字＋局部公式、单个符号与整条式，中文不乱序 |
| F08 | 长求和/分段式，含绝对值与≤ | 横向滚动后仍能精确命中边界；单符号与子式不受换行/滚动错位影响 |

LaTeX实际字符串及目标在实现fixture时冻结到manifest，不能一组换更容易的公式。允许表达式序列化补必要分组/空白，但不能多带未选项、改变语义或冒充原LaTeX字节一致。必要人工数学核对和再渲染用于验证，不调用模型解释选区。

## 4. 操作与交叉场景

1. 每组先渲染原式，记formula_id、message_revision、原表达和版本；确认排版无错。
2. 不输入LaTeX，以鼠标完成每个指定目标；记录可见高亮、公开选区、导出表达、预览和加入草稿内容。
3. 移除/重新选择、连续加入多引用；已有文字和图片草稿不丢。整式/整步快捷入口单独验。
4. 改变窗口/浏览器缩放及Windows缩放环境，测试长式滚动、浅深色、中文输入法、键盘焦点及复制。
5. 在流式追加/未闭合公式fixture中，检查当前选择不被无关增量刷新；必要时冻结可选择的已完成块，不把半式错误渲染为最终内容。
6. 集成到自由窗口时，标题拖拽、PDF文字选区和公式选择不互抢；遮挡视频不改变播放。组件试验与应用集成证据分开。
7. 断网查看同一公式与引用，所需字体/样式本地可用；若离线查看仅需显示，不擅自增加离线选取产品需求。

## 6. 通过与候选选择

单符号/子式、整式/整步均能按预览准确加入且来源版本稳定；无常见结构持续错误；公开接口/有限映射可维护。对规范化表达，逐项检查数学与选取范围，不强求无关空白/花括号字节相同。

若仅整式可用、选分母常多带分子、必须大量私有DOM类/源代码分叉，则该候选未通过。先比较另一候选/有限适配；两者均有重大限制时给出证据与最小调整，建议用户重新决策，不自行降低完整首版要求。

最终采用一条主要数学渲染链。报告只写候选比较/建议，不因隔离成功就标自由多窗/正式UI已验；D-01完成还需其实际引用持久化/集成证据。
