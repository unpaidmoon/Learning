## 1. 待证假设与历史边界

独立本地GPU worker可在数学课产出有用辅助字幕，时间定位/手改可靠，受控后台不破坏播放、截图和当前问答。转写完成/长暂停后资源可释放，按需片段不复活手动暂停的批量队列。

旧60秒记录仅说明进程内修正DLL后局部推理可行，末尾61.43/62.65秒越过60秒窗口；无数学听写真值和整课/前台并行证据，本轮不重述为新测试。不要直接按4秒/60秒外推整课承诺。

## 2. 执行前准备

| 项目 | 要求 |
| --- | --- |
| 授权 | 允许的音频文件/时间窗、GPU推理、采样和依赖准备明确；不自动解码视频画面，不上传音频 |
| 固定环境 | 项目独立Python、faster-whisper/CT2 wheel、VC++/CUDA/cuBLAS/cuDNN的实际来源/版本/DLL路径；不依赖用户全局PATH偶然可用 |
| 模型 | 复用已登记turbo snapshot作为候选，核完整文件/revision/hash与许可；链接目标存在不等于加载/推理通过，不新下模型 |
| 音频 | 有限时段、单声道16kHz候选；记录截取方式、实际采样数/时长、原视频绝对起点，禁止整课PCM常驻 |
| 真值 | 对每个窗口人工听写并标数学词/关键字母、正负号、上下限及时间锚点；人工核对者与来源记录 |
| 并行阶段 | 真正播放器/截图/业务/Harness可运行；合成流只可代替部分压力fixture，不算真实问答并行通过 |

固定模型/计算类型/beam/VAD/线程等基线，一次只改少量变量。测试模型提示词/术语表不得夹带整份讲义，也不新增字幕AI纠错请求。

## 3. 最小音频窗口矩阵

每类先一个约30—60秒窗口，静音可更短；具体起点在授权与人工听写后冻结，不任意浏览用户课程内容。可在授权后复测旧600—660秒窗口，但旧登记不自动授权新实验。

| ID | 内容 | 观察 |
| --- | --- | --- |
| ASR-01 | 正常中文数学讲解，含字母/术语 | 有用文本、数学关键词/符号含义，关键错误不因总体字数好看被掩盖 |
| ASR-02 | 正负号、积分上下限、趋近方向等口述 | 关键条件影响，不能静默推翻用户题图 |
| ASR-03 | 停顿/静音/很短话语 | 幻觉、重复、无语音判定 |
| ASR-04 | 语句跨两个片段边界，带重叠 | 绝对时间、重叠去重、漏词/重复、手改片段身份 |
| ASR-05 | 非零起点与容器/音频起始偏移 | 局部→原视频时间换算，不把输出相对秒当绝对秒 |
| ASR-06 | 窗口尾部截断，复现已记录越界条件 | 原始segments、越界诊断、对齐策略；简单截断不算修复精度 |

建议初始采用“导航锚点偏差不超过2秒”作为试验候选判据，执行前在run-record冻结并说明只面向来源跳转，不代表逐字对齐；若实际用途需其他容差，在采集前说明理由，不在看到失败后悄悄放宽。任何发布的时间必须在有效源范围且start≤end。

## 4. 分阶段步骤与用例

### A：依赖与时间轴组件

1. 核模型与音频权限/实际时长；显式worker子进程DLL搜索目录并保持必要句柄，不改系统设置。
2. 冷加载、首次推理、同段warm各记录；lazy segments必须实际迭代到产物，import/加载成功不能算推理成功。
3. 保存未经修正的原始segments、词/段时间、检测时长、模型参数与异常；不只保存SRT最终文本。
4. 按人工真值核文本与时间；越界保留原始诊断，修分片/偏移/对齐后复测原例和另一个边界例。可限制UI安全跳转，但仍标时间轴未合格。

### B：持久队列、手改与资源

| 用例ID | 操作 | 通过条件 |
| --- | --- | --- |
| V6-01 | 导入缺可用字幕的视频/课程 | 自动安排唯一整课任务，当前观看优先；已有有效产物不重复整课 |
| V6-02 | 当前问题需要未覆盖片段、批量队列暂停 | 临时按需片段可自动处理，结束批量仍暂停，用户可停止该片段 |
| V6-03 | 单片段推理中暂停/请求更高优先级 | 明确在片段边界生效，不假称即时抢占GPU；已提交检查点复用 |
| V6-04 | worker崩溃/重启/源文件改版 | 只重做未提交片段；旧源产物拒绝发布，重复任务/回调不重复入库 |
| V6-05 | 用户手改后旧结果返回；随后检索/显示 | 手改不被覆盖，有效文本/索引随修订更新，原始转写保留 |
| V6-06 | 尚未处理与已处理未命中 | 状态不同；字幕未就绪不阻塞充分题图，不自动联网 |
| V6-07 | 正常完成/持续失败 | 正常安静更新进度；需要介入才主动提醒，无完成弹窗/声音 |
| V6-08 | 完成/长期暂停后释放，再按需重载 | 实际内存/显存释放、重载等待单记；保留产物/检查点/暂停意图 |
| V6-09 | 拔电源/默认与加速 | 电池继续转写，两种模式均服从前台；不自动省钱换模型或恢复暂停队列 |

“长期暂停”的释放阈值、片长/重叠和模式配额是待验证工程参数，先声明本轮候选值再测；记录真实生效值，不写虚构产品默认。

### C：真实前台并行及持续运行

用同一播放位置/交互任务比较：无ASR→默认处理→加速；有真实问答授权时加入Harness活动生成。先短组合，再在稳定后逐步延长，不直接把整课自动转写当首个试验。

观察播放帧/卡顿、输入/截图/裁剪/公式滚动延迟、当前片段插队等待、CPU/GPU/内存/显存、温噪与用户干扰。用户正常主流程为等并读完回答后返回视频，边播边问是另一已支持场景，两者均要实际观察。

不从一次采样最大值当绝对峰值；记录采样周期/漏峰边界。没有传感器或功率仪时标未知，不编精确功耗/噪声。默认低热噪用相同任务的相对资源与主观干扰说明，不用降低吞吐代替前台体验通过。

## 5. 通过、失败和交付

A：代表窗口产出文本，数学关键错误逐项可查；时间在有效范围，人工锚点达到冻结容差、无系统性漂移/段间重复。没有人工真值或容差未冻结则时间/准确性未验。

B：唯一队列/检查点/手改保护/暂停意图/资源释放全部有实证；一个GPU任务起步不意味着所有后续场景天然安全。

C：与基线相比没有可重复的明显播放/截图/输入阻滞，默认/加速均满足前台优先；真实组合与合成压力结果分开。

时间越界发布为可信引用、手改覆盖、暂停复活、资产丢失即对应项失败。先修依赖/分片/对齐/调度，不能自动改云ASR或恢复字幕AI纠错；持续资源干扰则调整队列/配额/释放策略再测。

交付固定环境/DLL/模型清单、原始segments与人工锚点、本地资源采样、各阶段结果、限界和未覆盖。音频/完整转写属于用户资料，默认留本地私有证据，不随源码入库。结束只清理本次worker/临时音频，确认GPU资源回收，不结束其他程序。
