Windows 云电脑／虚拟机验收

1. 将整个 ZIP 复制到云电脑或虚拟机内的本地可写目录并完整解压。可以使用中文和空格路径。不要直接从共享文件夹或 ZIP 内运行；无需安装 Python、Node 或 Rust。
2. 双击“开始验收.cmd”。自动检查会创建独立测试数据、检查真实窗口和后台崩溃恢复；使用自造资料，不调用模型、不修改系统启动项。检查完成后会打开手动验收窗口。
3. 在“独立运行恢复验证”课程打开 lesson.txt、示例.pdf，再播放示例视频.webm。检查阅读、切换、全屏和退出全屏。用视频截图选择一个范围、确认加入草稿，检查草稿可见；本次环境验收无需登录模型账号或发送问题。
4. 普通关闭窗口后，用“继续手动验收.cmd”恢复同一窗口和测试数据；随后从软件菜单或托盘明确退出，再运行同一入口，检查原内容和草稿仍在。
5. 在这台虚拟机里测试运行设置：若要验证Windows登录启动，请在软件中启用、实际重登Windows后检查启动结果；完成后可在同处关闭。睡眠／唤醒也单独记录。开启“任务进行时保持系统唤醒”不代表会阻止用户主动睡眠或合盖。
6. 本地OCR／字幕如未运行、设备不可用或提示缺驱动，按实际现象回报，不安装额外资源来把原结果改成通过。请将未执行项目标为“未测”。

离线检查只对验收用Electron会话启用离线并拒绝外网请求，不禁用云电脑网卡或更改系统网络；远程连接保持可用。交互书、参数图、卡片示例来自自造资料上的实际模型结果，不包含你的真实英语讲义。你也可以在“验收工具/离线示例”中用普通浏览器打开各index.html手动阅读、自测和交互。

“查看验收结果.cmd”显示自动摘要。“汇总验收结果.cmd”只打包环境、自动摘要和手动回报，不打包数据库、账号、浏览器目录、运行日志或手动窗口截图。
你可直接回复自动结果和逐项体验；也可填写“验收结果/手动回报.txt”。不要只用“能打开”代替其余分项。

自动使用的测试profile与结果均在包旁“验收结果”内，运行包本身不含密钥、账号、课程或用户素材。已有真实学习窗口与该虚拟机验收数据无关。
